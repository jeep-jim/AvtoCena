# Яндекс Директ — АвтоЦена

Формат: XML Авто.ру, UTF-8. Передача HTTP с Content-Encoding: gzip.

- Общий фид: https://avtocena.com/feeds/yandex-auto/all.xml
- Япония, Зелёный угол: https://avtocena.com/feeds/yandex-auto/green.xml
- Китай: https://avtocena.com/feeds/yandex-auto/china.xml
- Корея: https://avtocena.com/feeds/yandex-auto/korea.xml
- ОАЭ: https://avtocena.com/feeds/yandex-auto/uae.xml
- Грузия: https://avtocena.com/feeds/yandex-auto/georgia.xml
- Европа: https://avtocena.com/feeds/yandex-auto/europe.xml

В Директе добавить фид по ссылке, тематика «Автомобили», формат Авто.ру. Для общей кампании использовать общий фид; отдельные ссылки нужны только при раздельной настройке. Не подключать общий и его части к одной группе как разные товары: ID совпадают намеренно.

Цена — предварительный полный расчёт в RUB до Новокузнецка, включая доставку по действующему тарифу сайта. Автомобили на заказ; не заявлять наличие в России. Ссылка каждого объявления открывает конкретную карточку с тем же городом и расчётной логикой. Клиент может изменить город, и цена изменится. Расчёт зависит от актуальных курсов и исходных параметров; перед заказом подтверждается менеджером.

Япония — только текущий Зелёный угол. Проданные аукционные результаты, неактивные/просроченные предложения, записи старше 7 дней, строки без фото или полного расчёта не включаются. Фид использует текущие опубликованные данные источников, а не проверяет продавца при каждом рекламном показе. Неизвестные характеристики не выдумываются. VIN и служебные поля не выгружаются.

Метки для фильтров: custom_label_0 — china/korea/uae/georgia/europe/green; custom_label_1 — Новокузнецк; custom_label_2 — Под ключ, доставка включена. У каждого авто постоянный unique_id.

Генерация: GitHub Actions Publish Yandex Direct feed, каждые 3 часа (UTC :23) и после успешного обновления рынков. Фид строится вне веб-контейнера, чанки читаются последовательно. Одновременные генерации исключены. Две сменяемые копии в Object Storage; переключение метаданных только после проверки загрузки. При ошибке остаётся последний успешно созданный фид, после 24 часов без обновления endpoint отвечает 503. Пустая часть фида не выдаётся как валидная выгрузка. Изменение поколения каталога во время сборки прерывает публикацию; следующий запуск строит актуальную версию. Максимум gzip-файла 3 MiB; при превышении публикация останавливается с диагностикой, а не молча обрезает каталог.

Перед запуском маркетолог проверяет импорт и модерацию в Директе, географию кампании и тестовый переход. Доступность URL не равна принятию фида Директом и не гарантирует показы.

Официальные требования:
- https://yandex.ru/support/direct/ru/feeds/requirements-other-categories#autos
- https://yandex.ru/support/direct/ru/product-gallery/cars

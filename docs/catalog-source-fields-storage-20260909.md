# Характеристики и Object Storage: 9 сентября 2026

## Подтверждено

Che168 `carinfo/59769656` указывает specid 74703. Его API `specparam?specid=74703` возвращает 2998 мл и 381 л.с.; `specconfig` возвращает опции именно этого specid. API `/lang` объявляет язык ru. Проверка адаптера получила 204 поля в 21 группе и 17 фотографий, без записи изображений в Object Storage. Полные русские ответы параметров и опций сохранены как тестовые фикстуры.

Прежний сборщик не вызывал specparam/specconfig и пытался читать таблицу из HTML, получая страницу Security Verification. Теперь сначала используется штатный API комплектации. Несовпадающий specid отклоняется, конфликтующие значения не угадываются; параметры одинаковой комплектации повторно используются в памяти (не более 512 записей). Полная таблица не дублируется внутри raw.boundPageParameters: она сохраняется в sourceSpecifications.

Добавлена обработка уже собранных исходных объявлений Che168 без повторного поиска машин и без обновления цены продавца: обновляется таблица по specid, привязанному сохранённым carinfo. Выполнение и результаты массовой проверки ещё предстоит подтвердить. Проверочный процесс не публикует каталог.

В проверенной странице Encar 42316687 встроенные данные cars.base.spec содержат displacement=998; мощности в этом контейнере нет. Это не доказательство отсутствия мощности у источника вообще. Путь к дополнительной таблице мощности Encar ещё не подтверждён; исправленным этот участок не объявляется.

## Пожелания пользователя

Отсутствие кузова или привода не блокирует готовый расчёт (исправление PR845). Поиск через Алису остаётся отдельной вкладкой. Автоподстановка из ответа ИИ без подтверждённого источника недопустима; желаемое расширение — поиск точной модификации, показ источника и найденных полей, применение подтверждённых значений и пересчёт. Эта функция в текущей правке не реализована.

Окончательная публикация наполненных шести рынков и мощность Encar остаются незавершёнными. Не заменять финальную стоимость японского аукциона стартовой ставкой.

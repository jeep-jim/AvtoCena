## Как работает текущий код
1. REQUIRED_CATALOG_SOURCES определяет сайты каждого рынка.
2. fetchPage получает страницы, normalizeOffer извлекает карточки; sourceId и market проверяются.
3. fetchImages получает детали/изображения; снимки listing/detail сохраняются раздельно. Строк JSONL может быть больше, чем уникальных машин.
4. Нормализация, проверка происхождения характеристик и расчёт выполняются отдельными этапами.
5. Публикация должна проходить независимую проверку. Успешный сбор не означает достоверные характеристики.

Причина инцидента KCar: точность чтения hrspow была ошибочно принята за точность технической характеристики. Исправление PR #987 отбрасывает это происхождение мощности. Старые расчёты дополнительно очищаются при чтении.

## Условия приёмки — обязательный контракт пересборки
| Поле | Условие | При нарушении |
|---|---|---|
| Идентичность | source-ID, марка, модель и детали принадлежат одному лоту | Карантин записи, не объединять по похожему названию |
| Цена | Положительная, известна валюта и смысл поля; не аванс/кредитный платёж | Не считать полную цену |
| Объём | Явные единицы и доказательство точного объёма; округлённые литры не точные см³ | Не выдавать точный объём для расчёта |
| Мощность | Известны единицы и вид мощности; kW не hp; пиковая не 30-минутная | Не подставлять число, снять зависимый расчёт |
| Согласованность | ДВС >2000 см³ с <100 л.с. требует проверки | Новое правило реализовано; без подстановки 100; официальное доказательство может подтвердить исключение |
| Тип установки | ДВС/гибрид/электро не конфликтуют с исходными данными | Ручное уточнение, без автоматического расчёта |
| Возраст | Проверять год и доступный месяц, без выдуманного месяца | Пограничный возраст требует уточнения |
| Фото | Разные декодируемые изображения именно этой машины | Не объявлять галерею проверенной по URL |
| Наличие | Явная продажа/снятие для обычного рынка | Исключить из активной выдачи; 403/таймаут не равны продаже |
| Япония | Завершённая продажа, конечная цена JPY, дата, аукцион/лот, фото | На проверку; начальные ставки и итог с доставкой не заменяют цену продажи |
| Расчёт | Подтверждены все необходимые входные параметры и валюта | Собственная цена продавца, ручные поля; не брать параметры соседнего авто |
| Дубли | source-ID внутри источника; подтверждённая идентичность между источниками | Не складывать одинаковые записи |

Таблица описывает контракт приёмки, а не утверждение, что все пункты уже проверены для каждой машины. Реализованное новое правило и две исправленные проверки навигации прошли 27 целевых тестов. Полный CI и выпуск PR #987 ещё не подтверждены.

# 24 ноября 2026 — AJ System только для Японии

Владелец приостановил общую замену каталога до обсуждения правил. PR #1859 остаётся черновиком. Новое отдельное поручение: AJ System — только Япония; Auto API — Китай, Корея, ОАЭ. После этого шага остановиться.

## Подготовлено

- Из схемы и формы админки удалены AJ China/Korea. Старые флаги не могут включить источник. Удалены preview-формы; прежние API закрыты. AJ-клиент и квота отказывают вне японских таблиц до обращения к доступу, кэшу или поставщику.
- Поиск, модели, счётчики, карточки, рекомендации и дилерские подборки больше не выбирают AJ вне Японии. Старые `source=ajes` / `source=existing` для Китая/Кореи ведут к текущему каталогу; Япония сохраняет прежнее поведение.
- Подготовлена условная миграция ровно двух записей `sources.ajes_china_feed` / `sources.ajes_korea_feed` с закрытой копией, исходным ETag, проверкой остальных настроек и HEAD-проверкой неизменности японского доступа. История сохраняется.
- Три диагностических workflow, обращавшиеся только к AJ Korea, закрыты на уровне job. Прочие источники и расписания не менялись.

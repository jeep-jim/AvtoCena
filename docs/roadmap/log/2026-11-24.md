# 24 ноября 2026 — AJ System только для Японии

Владелец приостановил общую замену каталога до обсуждения правил. PR #1859 остаётся черновиком. Новое отдельное поручение: AJ System — только Япония; Auto API — Китай, Корея, ОАЭ. После этого шага остановиться.

## Подготовлено

- Из схемы и формы админки удалены AJ China/Korea. Старые флаги не могут включить источник. Удалены preview-формы; прежние API закрыты. AJ-клиент и квота отказывают вне японских таблиц до обращения к доступу, кэшу или поставщику.
- Поиск, модели, счётчики, карточки, рекомендации и дилерские подборки больше не выбирают AJ вне Японии. Первоначальная версия перенаправляла старые AJ selectors в текущий каталог; после уточнения владельца этот API-контракт заменяется явным 410 для удалённого источника. Япония сохраняет прежнее поведение.
- Подготовлена условная миграция ровно двух записей `sources.ajes_china_feed` / `sources.ajes_korea_feed` с закрытой копией, исходным ETag, проверкой остальных настроек и HEAD-проверкой неизменности японского доступа. История сохраняется.
- Три диагностических workflow, обращавшиеся только к AJ Korea, закрыты на уровне job. Прочие источники и расписания не менялись.

## Подтверждённая причина запроса

[Запуск 45321457924](https://github.com/jeep-jim/AvtoCena/actions/runs/45321457924) в 10:51:46 по Красноярску завершился с `home_host_aj_http_china-ajes_timeout_no_status`. Это ровно `/api/catalog/search?market=china&source=ajes&pageSize=24`: после удаления AJ-selector он идёт в прежний ordinary China search. За 90 секунд HTTP status не получен. Квитанция: `accepted=false`, `failedPhase=aj-private`, `lastCompletedPhase=identity`, `ingressState=retained`, `remoteClosed=true`; cleanup/close прошли. Миграция read-only, ревизия 18. ZIP квитанции SHA256 `1c9b1af9d1bad0374bb2d3184a1d45696defb17ab21831b67418b7dbebd7e052`.

Prepared reader в `53af5997` побайтно совпадает с установленным `22867cbc`: обычный нефильтрованный запрос последовательно читает все relevant parts. Отдельный контроль того же no-source запроса на старом публичном сайте не ответил за 45 секунд; Корея вернула HTTP 200, 24 карточки. Это подтверждает существование тяжёлого пути до AJ-выпуска, но не является полным измерением всех страниц.

После этого была локально подготовлена небольшая оптимизация чтения Китая, но владелец повторно указал: поручение касается только удаления больше не покупаемых источников. Оптимизация **не коммитилась, не публиковалась и исключена из выпуска**; каталог и его алгоритм чтения остаются прежними.

Уточнённый контракт: API-запрос `source=ajes` вне явного `market=japan` получает HTTP 410 `{ok:false,error:source_retired}` до выбора рынка, чтения каталога или поставщика. Он не запускает другой поиск. Custom AJ probes проверяют именно удаление источника; `source=existing` не является удаляемым поставщиком и больше не входит в эти probes. Все исходные 17 server routes, 51 samples, browser gates, deadlines и rollback сохранены. Это исправляет лишнее расширение задачи в прежней проверке, а не объявляет поиск Китая восстановленным.

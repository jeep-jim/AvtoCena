## Поручение

AJ System (Михаил) оставить только для Японии. Платные фиды Китая, Кореи и ОАЭ относятся к Auto API. Удалить неиспользуемые AJ-источники из админки и логики; остальные рынки, данные, расписания, энциклопедию и расчёты сохранить. Владелец отдельно остановил расширение этой задачи на ремонт поиска Китая. Общая замена каталога и PR #1859 остаются приостановленными.

## Почему выпуск затянулся

Сначала обнаружено несовпадение Docker image ID между сборкой и сервером. Совместимая сборка с проверкой save/remove/load принята в [PR #1861](https://github.com/jeep-jim/AvtoCena/pull/1861); безопасная диагностика — в [PR #1862](https://github.com/jeep-jim/AvtoCena/pull/1862). Затем [45321457924](https://github.com/jeep-jim/AvtoCena/actions/runs/45321457924) выявил 90-секундный таймаут поиска Китая, который ошибочно запускался вместо удалённого AJ-источника. После уточнения владельца этот fallback заменён явным 410. Подготовленная локально оптимизация чтения Китая не коммитилась и не публиковалась; в source `fe289d7e` её нет.

[45326146642](https://github.com/jeep-jim/AvtoCena/actions/runs/45326146642) остановился до обращения к серверу из-за параллельных автоматических проверок. После их завершения выполнена одна повторная установка того же кода. Дополнительные post-merge проверки имели отдельные таймауты: scroll restoration в browser fixture и discovery карточек на ещё прежнем публичном сайте. Их исправление в этот шаг не включалось.

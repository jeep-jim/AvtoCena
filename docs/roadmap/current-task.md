# Текущая задача: физически удалить AJ вне Японии

24.11.2026, Asia/Krasnoyarsk.

| Поставщик | Рынки |
| --- | --- |
| Михаил — AJ System | Япония |
| Auto API | Китай, Корея, ОАЭ |

## Поручение владельца

Полностью убрать неиспользуемые подключения AJ Китая и Кореи: интерфейс, реализацию запросов/нормализации/кэширования этих рынков, диагностические задания и действующие указания о покупке или подключении. Выключенных переключателей и отказа старого API недостаточно.

Японское подключение и сохранённый общий доступ остаются. Данные других поставщиков, энциклопедия и движки расчётов сохраняются. Общую замену каталога не начинать: следующий этап — согласование документов и правил с владельцем.

## Проверенный исходный статус

- [Миграция 45312083161](https://github.com/jeep-jim/AvtoCena/actions/runs/45312083161) удалила две записи источников, ревизия 18. Японский доступ и остальные настройки сохранены; автомобили не записывались, поставщики не запрашивались.
- PR #1860 и #1863 убрали регистрацию/формы и закрыли старые обращения, но оставили неиспользуемый код и противоречащие документы. Прежняя формулировка «код очищен» была неполной.
- [Установка 45327054971](https://github.com/jeep-jim/AvtoCena/actions/runs/45327054971) не переключила сайт: общий сценарий остановился на обычной странице Китая с Volkswagen. Это условие нашего сценария, не требование GitHub и не доказательство участия AJ в выдаче Китая.
- Последний проверенный публичный runtime — `22867cbcfaee27b2e8917b6bf880e44827f67b60`. Установка новой очистки ещё не подтверждена.

## Текущая очистка

В рабочей версии физически удалены CN/KR реализации AJ, старые отчёты AJ, задания/маркеры и документ подключения. Япония сохранена. Минимальные ответы старым URL и отсечение прежних ID не являются доступным источником.

Адресные проверки AJ: 183/183; связанные проверки настроек, карточек и Auto API: 103/103; TypeScript — успешно. Сравнение японских SQL, нормализации и карточек с исходным кодом main не выявило изменения поведения. Точный runtime переносится отдельной поправкой к установленному исходнику, без переноса посторонних изменений из main.

Установка относится только к удалению AJ вне Японии. Проверки точного исходника, неизменности сохранённых разделов и расчётов, авторизации, владения записью, переключения и отката сохраняются. Общие замеры скорости каталога не объявляются повторно пройденными. Реальный owner-интерфейс нельзя выдавать за проверенный, если доступна только изолированная проверка компонента.

## Завершение

После подтверждённой установки записать release SHA и конкретные проверки, отчитаться и остановиться. Ремонт Китая, новые сборы и новые правила рынков не входят в этот шаг. PR #1859 остаётся черновиком. Подробности — [журнал 24 ноября](log/2026-11-24.md).

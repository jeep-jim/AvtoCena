Заменить накопившиеся загрузчики фидов, парсеры, правила допуска, расписания и публикации одной понятной системой. Каждый рынок получает полный разрешённый источник, обновляется независимо и обслуживает все фильтры по подготовленным данным. Админка, энциклопедия и движки расчётов сохраняются.

## Границы

| Область | Действие |
| --- | --- |
| Загрузчики, парсеры, source admission, старые recovery/backfill/publish jobs | Инвентаризировать, остановить, заменить и удалить из действующего пути |
| Автомобили, поисковые индексы, подготовленные карточки и их кэши | Подготовить заново; переключить после проверки; старые удалить после подтверждённого возврата |
| Админка, её настройки рынков и источников, секреты | Сохранить без изменений; читать существующую конфигурацию через адаптер |
| Энциклопедия, справочники, редакторские значения и статусы | Сохранить без изменений |
| Расчётные движки и бизнес-настройки | Сохранить; фиксировать их версию, курс и время для каждой подготовки рынка |
| CRM, пользователи, дилеры, подборки, избранное, сохранённые расчёты | Сохранить, включая ссылки на прежние идентификаторы машин |

`catalog/` не является целиком удаляемым разделом: внутри находятся `catalog/operations/collection-controls-v1.json`, справочники, архивы и управляющие объекты. Удаление допускается только по точному проверенному перечню.

## Контракт нового рынка

Для каждого рынка отдельно фиксируются: поставщик и оплаченный способ доступа; источник фактической конфигурации; полный snapshot или delta с подтверждённым завершением; идентичность объявления; явные условия допуска и причины исключений; правило снятия с продажи; расписание и допустимый возраст данных; версия энциклопедии, расчётов и курса; готовые фильтры, цены, карточки, отчёты и рекомендации.

Строка частоты в интерфейсе админки не подтверждает реальный cron. Конец доступного окна поиска не подтверждает полный каталог поставщика. Счётчики должны сводиться: получено → уникальные → исключено по каждой причине → опубликовано. Неизвестные параметры не подменяются догадками.

## Новый путь данных

Существующие настройки → сохранённый источник → нормализация с прежними ID → явные правила рынка → существующие энциклопедия и калькуляторы с фиксированным контекстом → неизменяемые карточки и полный индекс → проверка → атомарное переключение только этого рынка.

Пользовательский запрос не собирает рынок и не пересчитывает его. Общий каталог объединяет принятые разделы. Неудачное обновление оставляет прежний раздел. Изменение одного рынка не меняет данные соседей. Старый конвейер не вызывается как fallback новой системы.

## Критерий завершения

На публичном сайте проверены полная выдача, все фильтры и скорость; источник и исключения объясняют объёмы; очередное обновление проходит само; соседние рынки не меняются; старые обработчики не могут переписать каталог. Ни наличие новой ветки, ни зелёный CI сами по себе этого не подтверждают.

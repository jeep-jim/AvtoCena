# Короткий роад АвтоЦены

Обновлено: 23.11.2026, Asia/Krasnoyarsk.

## Как продолжать работу

1. Прочитать этот файл и [текущую задачу](current-task.md).
2. Открыть только нужное направление: [фиды и расписания](feeds.md) или [скорость фильтров и страниц](performance.md).
3. Проверить конкретный код, запуск или страницу, нужные для следующего действия. Записать результат коротко в документ направления и [журнал 23 ноября](log/2026-11-23.md).

При изменении фидов соблюдать [ограничения источников](source-policy.md): исправления не меняют квалификацию, условия допуска карточек и разрешения на публикацию.

Старый большой роад и его разбитый архив удалены из рабочей версии по прямому поручению владельца. Нужные для текущей задачи правила и результаты находятся в коротких документах. Не восстанавливать и не читать историю Git без отдельной просьбы.

## Что сейчас делаем

| Направление | Цель | Статус этой записи |
| --- | --- | --- |
| Фиды | Подготовленные данные каждого рынка корректно публикуются | Проверяется |
| Расписания | Обычные обновления срабатывают с согласованной периодичностью | Проверяется |
| Фильтры | Быстрая выдача с правильными карточками и счётчиками | Проверяется |
| Страницы | Быстрая загрузка полного полезного содержимого | Проверяется |

Статус «проверяется» не означает, что исправление опубликовано. Подтверждения, ссылки на запуски, SHA и измерения записываются по мере получения фактических результатов.

## Размер документов

Рабочий документ содержит текущий результат, следующий шаг и препятствие; он не накапливает пересказ всех прежних попыток. Цель — до 100 строк / 10 KiB на документ. Большой журнал делить по дням или отдельным завершённым задачам. Подробные машинные логи не вставлять в рабочие документы.

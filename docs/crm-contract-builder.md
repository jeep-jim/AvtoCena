# Конструктор договоров CRM — 24.09.2026

Раздел `/crm/documents`: два редактируемых шаблона, образцы с водяным знаком,
черновики с автосохранением, готовые версии, PDF, печать, системная отправка файла
и прикрепление к документам клиента. Подписанный экземпляр загружается через
существующую карточку клиента.

## Основа текстов

Исходники владельца: «ИП Молодых Япония.pdf» (9 страниц) и общий договор,
предоставленный в PDF Toyota C-HR (8 страниц, заполненный под Грузию).
Сохранены порядок и содержание разделов. Переменные: клиент, дата, автомобиль,
рынок, место передачи, срок доставки, комиссия и обеспечительный платёж.
Убрано повторное агентское вознаграждение 70 000 ₽ в японском п. 2.2 согласно
пояснению владельца: это тот же первоначальный платёж. Исправлены неверные
внутренние ссылки на номера разделов и оставшееся чужое ФИО в приложении.
Для остальных рынков сохранено отсутствие отдельного раздела о расторжении.
Юридическая переработка условий не выполнялась.

## Хранение и права

`contracts/builder-templates/`: зашифрованные шаблоны, редактируемые только владельцем.
В исходном коде реквизиты исполнителя ограничены наименованием ИП, ИНН, ОГРНИП
и банковскими реквизитами. Паспорт, дата рождения и домашний адрес исполнителя
из приложенных документов в git не помещаются; при необходимости владелец
добавляет их в редакторе шаблона, в зашифрованном хранилище.
`contracts/records/`: зашифрованные записи, включая паспортные данные и версии.
Ключ шифрования тот же, что у документов клиентов. Его нельзя терять при ротации.
`contracts/index.json`: индекс без паспортных данных.
`contracts/numbers/YYYY-MM-DD.json`: атомарное выделение номера по московской дате.
Менеджер видит созданные им договоры; привязанный клиент дополнительно проверяется
по действующим правам CRM. Владелец и администратор видят договоры команды.
Сохранение защищено номером ревизии от перезаписи из другого окна.

Расчёт по ссылке выполняется заново действующим движком сайта; ранее сохранённые
параметры автомобиля используются, но старые суммы не копируются. Расчёт можно
внести вручную с указанием курса и даты. Готовая версия фиксирует данные и текст;
изменение шаблона или черновика не меняет старые версии. До готовой версии PDF
имеет водяной знак «ЧЕРНОВИК». Повторное прикрепление одной версии не дублирует файл.
Отправка использует системное меню файла, если браузер его поддерживает; иначе
пользователь скачивает PDF и отправляет самостоятельно. Электронная подпись не
внедрялась.

Проверки: `tests/crm-contracts.test.ts`, `CRM_TEST_PAGES=documents,leads node
 tests/browser/crm-mobile-layout.mjs`, типизация. Браузерные тесты используют
синтетические записи, без отправки клиентам и без изменения рабочей CRM.

## Исправления

- Короткая пауза после отказов:visitor_restricted5мин по фактическому IP,quota_exhausted30с по пулу, другие известные временные ошибки30с по запросу/посетителю. Нет подменыIP, повышения/сброса квоты, фонового повторного обхода. Свежий общий успешный кэш остаётся доступен.
- Уже показанная строка списка пригодна для карточки при отказе полной загрузки. Только тот жеID/таблица, не старше7дней; не выдаётся за полный ответ, не выдумываются недостающие поля и аукционный лист. В памяти не более600строк/4МиБ. Для холодного процесса читаются только существующие128слотов приватного кэша, по8параллельно, индекс до6МиБ/60с. Никакого скачивания каталога.
- Ожидаемый отказAJES в layout больше не выносит карточку в ошибку всего публичного раздела. Кнопки «Повторить» действительно перезагружают серверный маршрут, включаяlayout.
- Японские карточки не запрашивают полныйлот приhover/focus/pointerdown; запрос при открытии. Справочники моделей кэшируются целиком30мин, только после успешного полного чтения, до4МиБ/16вариантов. Доступ подчинён выключателю рынка/источника.
- Общий заголовок «Авто под заказ», хлебные крошки и отдельное «Япония · количество» над выдачей; убрана техническая плашка времени кэширования. Дата кэширования не была датой ограничения статистики. stats — трёхмесячная статистика по документации поставщика; полнота всей базы локально не аудировалась.
- Coaster внесён в общее исключение тяжёлых семейств, SQLсписка/счётчика/справочника и локальная защита согласованы. Основание — официальные спецификацииToyota; лёгкиеHiace/kei не исключены. Старые списки могут быть резервно прочитаны с новой локальной фильтрацией, старые счётчики с иным отбором не переиспользуются.
- Поиск по KUZOV и LOT сохранён; добавлено отдельное SERIAL для полного номера кузова. Вход строго проверяется, начальные нули сохраняются, одинаковые условия для списка/счётчика/моделей. Живой ответSKE/30132 ещё проверяется отдельно: unit-тест не доказывает доступность источника.
- В стандартном порядке внутри даты известные поTIME гибриды/EV не продвигаются перед остальными. Порядок применяетсяSQLдо пагинации; явные сортировки цены/года сохраняются. ПустоеTIME не разрешает угадать тип двигателя.
- Повторные клиентские чтения превью расчётов используют30с памяти вместо1с; сохранение расчёта/смена курса/фокус по-прежнему инициируют обновление. GETпоискаЯпонии и счётчиков получают краткийprivateкэш браузера; персональныеHTML/CRMв общий кэш не помещаются.

# Скорость каталога и подгрузка — 19.09.2026

Задача владельца: устранить зависания, заменить цифровую пагинацию на удобный просмотр с сохранением уже показанных автомобилей на десктопе и телефоне. Полный аудит шести рынков и формул — следующий этап, пока не объявлен завершённым.

## Подтверждённые причины и изменения

- Ранее одна стандартная страница рынка вызывала `searchOffers` восемь раз для окна разнообразия. Каждый вызов заново фильтровал и сортировал проекцию рынка. Теперь окно получает один внутренний ограниченный запрос; публичный лимит API остаётся 48. Новый интерфейс выдаёт по 24 карточки.
- Для японских расчётов превью требуются полные записи; готовые расчёты ранее сохранялись всего на 60 секунд. Повторное использование увеличено до 15 минут, ключ по-прежнему включает обновление предложения, исходную цену, конфигурацию и день расчёта. Формулы и условия допуска цены не изменены.
- Добавлен ограниченный серверный кеш готовых страниц: 32 записи, 12 МБ сериализованных данных, 60 секунд, объединение одновременных запросов. Публичный поисковый API допускает кеширование на 30 секунд. Ошибки не записываются как успешный ответ.
- Убраны четыре автоматических запроса полных карточек через 120 мс после открытия страницы; предварительная загрузка остаётся по намерению перейти. Первые видимые фотографии загружаются сразу, остальные лениво.
- Японские обложки используют 400px-версию того же файла и каталога лота у источника. Проверенный пример `1881816509/400/1789240274.5197_2.webp`: HTTP 200, 17 790 байт. При ошибке миниатюры клиент переключается на исходный адрес. Галереи и аукционные листы не изменены; новые фотографии в Object Storage не копируются.
- В браузере исходной версии зафиксированы ошибки React #425/#422. Оформитель фильтров запускался из общего layout и мог менять серверную разметку до гидратации фильтра. Он перенесён внутрь компонента фильтров, чтобы запускаться после его монтирования. Исчезновение ошибки проверяется отдельно на опубликованной версии.

## Поведение просмотра

«Показать ещё» добавляет следующую порцию ниже, показывает число загруженных автомобилей и состояние ожидания. Повторный клик во время запроса не запускает дубль. Ошибка оставляет загруженный список и возможность повторить. Последняя порция завершает список. Возврат из карточки восстанавливает загруженные React-элементы и прокрутку в этой вкладке (до шести контекстов, срок 30 минут). Изменение фильтров создаёт отдельный контекст. Полная перезагрузка начинает с адресованной страницы; старые ссылки `page=` и переход без JavaScript поддержаны.

Нельзя обещать такую же скорость или ускорение каждому посетителю по одной выборке. Источник японских фото также отвечал медленно. Итоговые замеры и проверка публикации фиксируются в PR.

## Дополнение владельца: вернуть резерв курса

Восстановлена прежняя формула: отдельная последняя строка «Резерв на изменение курса» = округление 2% цены автомобиля в рублях. Сам официальный курс, пошлины, логистика и аванс не изменяются этой строкой. 2% подтверждены историей до PR #990. Активная политика всех шести рынков снова 2%, в том числе при сохранённом старом нуле. Ранее удалённые экспортные расходы не возвращаются.

Японские сохранённые расчёты: вычитается точная прежняя сумма резерва, добавляется новая от сохранённой цены авто; повторное применение не накапливает сумму. В компактной проекции сохраняется база цены авто; старые проекции получают её из полной записи. При отсутствии доказуемой базы новая сумма не выдумывается. Проверяются совпадение списка и карточки, суммы строк и неизменность исторического курса.

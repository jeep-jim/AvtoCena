## Наблюдения и границы вывода

Мониторинг последнего дня открылся; видны многосекундные задержки и ошибки. В текущих REPORT (09.10 04:30 UTC+3) есть запросы длительностью 12,8–23 секунды. Один из запросов 12,823 секунды имеет Billed Duration 11 секунд; текущие отчёты также показывают Max Memory Used до 2152 МБ. Это точечная выборка 09.10, а не измерение распределения за 08.10 и не основание немедленно уменьшать память до 2 ГБ.

Исторический поиск прикладных логов за 08.10 через Cloud Logging после ожидания и одного reload завершился видимой internal error («Произошла непредвиденная ошибка»). Текущие логи и мониторинг доступны; блокировка относится к этой исторической выборке. Не установлены доли конкретных маршрутов, cache miss, Object Storage ожиданий, ботов, cold start, тестовых прогонов и CPU-работы. Нет доказательства, что весь рост вызван аварией Яндекса или Che168.

Recovery Che168 выполняется на GitHub-hosted ubuntu-latest, а не в avtocena-web. Он обращается к Object Storage, но его ожидание API нельзя считать временем выполнения web-контейнера Яндекса. Полная атрибуция исходящего трафика runner требует отдельной проверки.

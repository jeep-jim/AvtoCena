# Задержка каталога — 19.09.2026

Продолжение исправления скорости по прямому запросу владельца. Предыдущие изменения интерфейса оставили нестабильную загрузку; эта работа посвящена серверному чтению и лишним фоновым запросам.

## Подтверждённые причины

- Профилирование опубликованных данных: поиск 24 японских машин — 1959/153 мс (первый/повторный проход); настройки и курс — 1260/0 мс; чтение 24 полных записей четырьмя работниками — 4266/4156 мс; сами расчёты — 25/8 мс. Восьми записей кеша полных блоков недостаточно для этой последовательности, повторный проход снова читает хранилище.
- Общий `PublicUiEnhancer` на каталоге и в карточке запускал предназначенный главной странице поиск с расчётом 48 машин всех рынков. В браузере этот лишний запрос занимал до 11 секунд и конкурировал с нужной загрузкой.
- Контрольный браузерный прогон до исправления: новая порция — 14041, 47057 и 9357 мс на ширинах 390/1440/390. Задержка приходилась на ожидание ответа POST `/cars`, а не передачу его небольшого тела. [Исходный профиль](https://github.com/jeep-jim/AvtoCena/actions/runs/35427330175).

## Изменения

- Японское превью использует компактный индекс исходных параметров, привязанный к поколению каталога, ревизии предложения, исходной цене и валюте. При отсутствии подходящей записи сохраняется прежнее чтение полного предложения. Неизвестные параметры не подставляются.
- Индекс содержит исходные параметры, а не готовые цены: расчёт выполняет прежний движок с текущими настройками. Совпадение полных результатов старого и нового пути проверяется перед публикацией индекса. Записи автомобилей и manifest этой операцией не изменяются. Обычная публикация каталога также формирует индекс из того же компактного представления, которое сохраняется в хранилище.
- Фоновые запросы статистики главной запускаются только на главной. Запрос количества использует `countOnly=1` без расчёта карточек. В API поиска добавлены измерения `Server-Timing` для чтения и расчёта.
- Номера страниц, «Показать ещё», сохранение списка, редакторы параметров и резерв курса 2% сохранены.

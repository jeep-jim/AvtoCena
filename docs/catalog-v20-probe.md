# Catalog production v20

1. Каждый shard сначала проверяет только утверждённые источники своего рынка.
2. Источник допускается к полной сборке только если первая страница возвращает хотя бы одно нормализованное объявление с реальной ценой и ссылкой на карточку.
3. Старые и автоматически зарегистрированные адаптеры не добавляются в production-проход без явного включения в source plan.
4. Фотографии из листинга кэшируются раньше детальной страницы. В быстром проходе одной подтверждённой фотографии достаточно для сохранения карточки; предпочтение по сортировке остаётся за галереями от шести фото, максимум — 30.
5. Остаток каталога хранится не более трёх дней и добавляется только после живого обхода.
6. Таможня, утильсбор, цена и publication gate не ослабляются.
7. Мёртвый источник должен быть обнаружен probe за секунды, а не удерживать весь workflow часами.

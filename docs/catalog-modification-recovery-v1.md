# Восстановление каталога и выбор модификации — v1

Решение владельца: 2026-09-06. База: `2c7aa77f97d495b2d27ec3f296788ed2bafd917a`.

Работа продолжается поверх существующих адаптеров, расчётов и хранилища. Покупка базы не является условием первого этапа. Приоритет — восстановить сохранённые неяпонские предложения; новые источники допускаются к дальнейшей работе только при доказанном разрешённом доступе и возможности получить расчётные данные.

## Поведение

- Достаточные доказанные характеристики и полный расчёт: обычная карточка с ценой.
- Объявление имеет подтверждённые идентичность, цену, год и фотографии, но модификация неоднозначна: «Выбрать модификацию», если существуют проверенные совместимые варианты с необходимыми расчётными полями.
- Нет подходящих проверенных вариантов, неверная исходная цена или идентичность: внутренняя очередь уточнения; массовая публикация пустых карточек запрещена.
- Топливо, объём, мощность и остальные зависимые параметры выбираются из одной версии. Неполные, исследовательские и конфликтующие записи справочника не используются как готовые варианты.
- Выбор пользователя создаёт персональный сценарий. Он не подтверждает комплектацию продаваемой машины, не меняет общую карточку, не обучает справочник и не создаёт общую цену/SEO Offer.
- Пока выбор не завершён, итоговой цены нет. Карточки без цены не попадают в бюджетные фильтры и не сортируются как нулевые цены.

## Измеримый результат

Цель владельца — не менее 80% автоматически рассчитанных машин в принятом неяпонском каталоге. Пользовательские сценарии в числитель не входят. Пример около 10 тысяч карточек — ориентир, а не обещанное количество или обязательная квота.

Контроль доли выполняется после отбора и дедупликации, отдельно по рынкам и в целом. На четыре автоматически рассчитанные карточки допускается максимум одна карточка с выбором модификации: A / (A + floor(A/4)) >= 0.8. При A=0 карточки с выбором не заполняют рынок. Отчёт сохраняет также исходный знаменатель, отказы и потери: сокращение набора не считается исправлением исходных данных.

## Границы

`productionWrites=false`, `publishAllowedMutations=false`, все существующие source `publishAllowed=false`. Исследовательские статусы источников и условия использования сохраняются. Обновление правил UI не разрешает запрещённый сбор данных.

Япония полностью вне текущего восстановления: не читаются её сохранённые чанки, не выполняются пробы, не меняются японские адаптеры или controls. Новая логика выбора применяется только к пяти неяпонским рынкам.

Production Object Storage, public generation/manifest, расписания и cleanup остаются заморожены. Чтение сохранённого каталога выполняется в GitHub Actions с жёстким GET-only envelope; локальные отчёты и артефакты не публикуют каталог.

## Приёмка

Проверить согласованность выбора, запрет неизвестных/чужих variant ID, отсутствие подстановок из review/средних, изоляцию пользовательского сценария, отсутствие неполной итоговой суммы, фильтры/сортировку, неизменность пригодных исходных карточек и паузы. Выполнить read-only отчёт по сохранённым данным. Успех workflow отдельно от достижения продуктовых целей и разрешения production-публикации.

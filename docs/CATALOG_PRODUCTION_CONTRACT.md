# AvtoCena — постоянное ТЗ каталога

Этот файл является внутренним каноническим ТЗ проекта. Его правила обязательны для всех будущих изменений каталога.

## Цель

Публичный каталог `https://avtocena.com/cars` должен содержать до 30 000 уникальных актуальных автомобилей по каждому из 7 рынков:

1. Корея
2. Япония
3. Китай
4. ОАЭ
5. Европа
6. Грузия
7. Кыргызстан

Максимальный общий объём — до 210 000 карточек.

## Обязательные источники

Единственный машинно-читаемый источник истины: `apps/web/lib/catalog/required-catalog-sources.ts`.

Каждый указанный там сайт:

- всегда участвует в парсинге своего рынка;
- не может быть заменён дополнительным сайтом;
- проверяется и отчитывается отдельно;
- должен иметь зарегистрированный реальный адаптер;
- может временно вернуть ошибку или блокировку, но это не отменяет сбор остальных источников.

Дополнительные источники разрешены только сверх обязательного набора.

## Поля карточки

Данные берутся из конкретного объявления или лота:

- стабильный ID источника;
- ссылка на оригинальную карточку;
- марка и модель;
- год;
- цена и валюта;
- пробег, когда указан;
- мощность, когда указана источником;
- двигатель, топливо, коробка и привод, когда указаны;
- фотографии именно этого автомобиля;
- дата получения и обновления.

Запрещено смешивать цену, параметры или фотографии разных объявлений.

## Режим без базы знаний

Текущий production-парсинг работает без обогащения из базы знаний.

Если поле отсутствует на сайте, оно остаётся пустым. Запрещено придумывать мощность, двигатель, комплектацию или пробег.

Таможенный расчёт после парсинга разрешён, но не должен подменять исходные характеристики объявления.

## Сбор и публикация

- Лимит: до 30 000 валидных уникальных карточек на рынок.
- Все 7 рынков собираются независимо и параллельно.
- Ошибка одного рынка не блокирует остальные рынки.
- Результат каждого рынка публикуется отдельно.
- Пустой результат не перезаписывает рабочий рынок.
- При повторном запуске карточки объединяются по стабильному ID.
- Данные предыдущих успешных запусков сохраняются 3 дня.
- Публикация выполняется через JSON Object Storage и существующий chunked manifest.
- На сайте отображаются только карточки, прошедшие проверку обязательных полей и качества.

## Расписание

Работает только один основной production-оркестратор:

`.github/workflows/catalog-v4-all-markets-30k.yml`

Он запускает все 7 рынков:

- вручную;
- автоматически один раз в сутки;
- без цепочки дополнительных автозапусков.

Повторный суточный запуск не должен отменять уже идущую сборку.

## Контроль результата

Каждый запуск обязан сохранять отчёт по рынку:

- запланированные источники;
- обязательные источники;
- количество просмотренных и сохранённых карточек;
- количество опубликованных карточек;
- ошибки по каждому источнику;
- `generationId` опубликованного каталога.

Зелёный статус запрещён, если публикация не создала `generationId` или опубликовала ноль карточек для собираемого рынка.

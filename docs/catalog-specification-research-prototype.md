# Дополнение характеристик по кнопке — прототип, 9 сентября 2026

В карточке добавлен поиск характеристик через серверный Yandex Search API с генеративным ответом. До подключения API интерфейс явно сообщает, что поиск внутри карточки недоступен, и сохраняет внешнюю ссылку на Яндекс.

## Поведение

1. Сервер получает объявление по ID из текущего каталога. Произвольные URL и поисковые инструкции от посетителя не принимаются.
2. В поиск передаются марка, модель, год, рынок, модификация, объём и код двигателя из диагностического листа. VIN, контакты и пользовательские черновики не передаются.
3. Ответ рассматривается как предложение. Год, рынок и модель должны совпадать; для каждого поля требуется HTTPS-источник из списка использованных документов ответа. Это проверяет структуру и происхождение ссылки, но не доказывает истинность значения или точное совпадение комплектации.
4. Посетитель сверяет источники и явно выбирает «Модификация подходит — подставить». Кузов, привод и коробка появляются в пробной карточке; расчётные поля подставляются в редактируемую форму.
5. Расчёт использует существующий серверный калькулятор и отмечен как личный сценарий. Исходная цена и общая база не перезаписываются. Неизвестная 30-минутная мощность не заменяется пиковой.

## Подключение для испытания

Серверные переменные: `YANDEX_SEARCH_API_KEY` и `YANDEX_SEARCH_FOLDER_ID`. Ключ должен иметь доступ к генеративному поиску Yandex Search API (`search-api.webSearch.user`). Не использовать ключ Object Storage. Секреты не добавлять в Git и не передавать в клиентские NEXT_PUBLIC-переменные.

Документация: https://aistudio.yandex.ru/en/docs/search-api/api-ref/GenSearch/search

API-ключ в рамках этой работы не настроен. Реальный ответ сервиса и сквозной расчёт с найденными данными пока не проверены. Подстановка проверяется на синтетических ответах, они не публикуются как объявления.

Прототип ограничивает обращения на экземпляре сервера: не чаще раза в минуту, максимум 30 в час, таймаут 45 секунд. Перед массовым включением необходим общий лимит на стороне инфраструктуры/провайдера: лимит отдельного экземпляра не является глобальной квотой и Origin не заменяет авторизацию.

## Сбор и хранение

Workflow сборщиков, их очередь и публикация не изменяются. Поиск ничего не записывает в Object Storage: нет сохранения HTML, изображений, ответов ИИ или новых поколений каталога. При перезагрузке страницы личный сценарий сбрасывается.

## Проверка

Проверены: соответствие идентичности, отсутствие источников, противоречивые дубли, недопустимые единицы и ссылки, некорректные ответы, отсутствие подстановки пиковой мощности вместо 30-минутной, честный ответ при отсутствии конфигурации.

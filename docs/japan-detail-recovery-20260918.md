# Япония: характеристики, расчёт и аукционные листы

Владелец поручил полностью удалить прежнюю интеграцию из текущего проекта и будущих сборов, использовать все сохранённые характеристики и добавлять аукционный лист последним в галерею.

## Проверенные результаты

- Публикация 35321333754: удалены 1847 карточек прежнего источника, сохранены все 8021 ProAuctions. Поколение `gen_1789717947575_7eea23a0`.
- Контрольные суммы всех остальных рынков совпали. Общая проверка индексов: `mismatches=[]`, `invalidReady=0`.
- Исходный HTML сохранён для всех 11463 собранных карточек; повторное открытие списка и карточек для восстановления не требуется.
- В Corolla Cross `30222301` уже были 140 л.с., 103 кВт и 1800 см³. Причина скрытия мощности: отсутствовавшее поле происхождения мощности получало статус `estimated` при нормализации. Новые импорты сохраняют `source_exact`; прежняя запись восстанавливается только при совпадении таблицы, ID, URL и точного свидетельства мощности.
- На рабочем сайте поля карточки `02defbbae91fe890a6b1dc3c` заполнены. API расчёта вернул 2586104 ₽, `requiresConfirmation=true`, дата выпуска — `year_midpoint`. Объём из аукционных данных остаётся редактируемым предположением и не превращается в подтверждённый точный рабочий объём.
- Лист принимается только из блока «Аукционный лист», с сервера изображений и из директории того же лота. Изображение декодируется и добавляется после фотографий автомобиля. Минимум две фотографии автомобиля проверяется независимо от листа.

## Удаление интеграции

Удалены адаптеры, задания сбора/обогащения, команды пакета, старые фикстуры, одноразовая миграция и записи характеристик прежнего источника. Сохранены независимые данные и их происхождение; исходные значения не переименовываются в сведения другого поставщика. Поисковый индекс и отчёты справочника пересобраны штатным валидатором. Локальные изображения марок используют нейтральные пути и не обращаются к внешнему поставщику.

## Публикация восстановленных листов

Подготовка: запуск `35321658779`, артефакт `proauctions-detail-patches`. Публикация запускается отдельным явным маркером после завершения подготовки. Публикуются только обновления уже существующих японских карточек; проверяются совпадение лота, цены, года, исходного URL, сохранность всех старых фотографий и контрольные суммы остальных рынков.

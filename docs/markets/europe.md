# Европа

| Параметр | Значение |
| --- | --- |
| Источник | Только mobile.de |
| Отбор | Восстановить прежний принятый набор параметров |
| Обновление | Раз в 3 дня |
| Порядок внедрения | После ОАЭ |

Владелец сообщил о прежнем объёме около 50 тысяч машин. Это ориентир для сверки потерь, а не искусственная квота. Точный прежний принятый набор параметров ещё требуется подтвердить; не подменять его сегодняшними ограничениями адаптера.

- Восстановить проверенный доступ к mobile.de и прежние параметры выборки; пройти все страницы, без скрытого общего предела.
- Убрать AutoScout24 из новой цепочки Европы. Сбой mobile.de не разрешает менять поставщика автоматически.
- Отдельно показать количество у источника, уникальные записи, причины исключений и итог публикации. Не объявлять прежний объём восстановленным по успешному запуску скрипта.
- До принятия нового снимка сохранять текущую европейскую выдачу и её реальную дату. Замена Европы не затрагивает соседние рынки.

В существующем коде `mobile_de_open` принудительно выключен, а `mobile-de-exact-source.ts` содержит собственные ограничения отбора. Это предмет этапа Европы, не правило новой системы и не условие работы Китая.

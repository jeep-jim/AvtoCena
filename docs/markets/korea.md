# Корея

| Параметр | Значение |
| --- | --- |
| Поставщик | Auto API |
| Источник | Оплаченный фид Encar |
| Год | С 2014 включительно |
| Обновление | Раз в 2 дня |
| Порядок внедрения | После Японии |

Правило 2014 заменяет прежнее обсуждение 2012. AJ System не участвует в корейском доступе, поиске, карточках или диагностике.

- Получать все доступные по оплаченному способу записи с полным обходом страниц и подтверждённым завершением. Каждое исключение имеет причину в сводке.
- Сохранять идентичность Encar, исходные технические факты и связи с энциклопедией. Не смешивать полную и компонентную мощность без доказательства.
- Страховая история, выплаты, осмотр и диагностика, доступные в купленных данных, сохраняются и открываются из карточки. Отсутствие сведений не означает «страховых случаев не было».
- В карточке показывать подходящие другие предложения Кореи и других рынков по принятым локальным данным. Ошибка нового фида соседа не убирает его предыдущие предложения.
- Цены, фильтры и рекомендации подготовить до публикации. Открытие страницы не запускает сбор или общий пересчёт.

Приёмка включает год 2014, поиск и `до 160 л.с.`, страховку на известных примерах, похожие предложения и совпадение цен списка с карточкой.

Общие условия: [contract.md](contract.md). Текущая стадия: [current.md](current.md).

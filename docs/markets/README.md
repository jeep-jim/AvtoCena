**Единый утверждённый план перехода всех рынков:** [migration-plan.md](migration-plan.md). Обычное обновление данных после миграции не пересобирает приложение; Япония сохраняет исключение AJ по полной загрузке. Все старые writers заменяются по рынкам после приёмки, не массовым удалением.

Прочитать [общие правила](contract.md), [текущий шаг](current.md) и **один документ нужного рынка**. Остальные материалы открывать только по конкретной зависимости. Статусы прежних запусков не являются командами к их повторению.

Правила утверждены поручением владельца. Их наличие **не означает**, что новая система уже установлена. Фактический результат и следующий шаг находятся только в [current.md](current.md), без многомесячного журнала в рабочем контексте.

# Грузия

| Параметр | Значение |
| --- | --- |
| Источники | MyAuto и AutoPapa, существующая конфигурация |
| Условия допуска | Сохранённые правила; проверить перед реализацией, не вводить скрытых новых ограничений |
| Обновление | Раз в 2 дня |
| Порядок внедрения | Последний рынок |

Источники: `myauto_georgia_list` и `autopapa_georgia_open` в `apps/web/lib/catalog/collection-controls-schema.ts`.

Для каждого источника проверять завершение всех страниц. Ошибка одного источника не доказывает удаление его автомобилей. Неполная попытка не заменяет принятый снимок Грузии. Объединение источников сохраняет идентификаторы и не создаёт дубликаты при повторе.

Сохранить расчётные настройки и энциклопедию. До переключения проверить источник каждого автомобиля, фильтры, цены, карточки и независимость расписания.

Общие условия: [contract.md](contract.md). Текущая стадия: [current.md](current.md).

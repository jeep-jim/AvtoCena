# ОАЭ

| Параметр | Значение |
| --- | --- |
| Поставщик | Auto API |
| Источник | Оплаченный фид DubiCars |
| Годы / цена / мощность | Без дополнительных ограничений загрузки; сохранить действующие условия расчёта |
| Обновление | Раз в 2 дня |
| Порядок внедрения | После Кореи |

Источник подтверждён записью `dubicars_feed` в `apps/web/lib/catalog/collection-controls-schema.ts`. Секреты и переключатель владельца сохраняются.

Полный снимок и дельты сохраняются в собственном хранилище. Проверять непрерывность курсора, уникальные объявления и явные снятия. Незавершённое обновление не заменяет действующую выдачу.

Сохранить расчётные настройки ОАЭ и привязки к энциклопедии. Подготовить цены и фильтры до публикации. Проверить очередное плановое обновление, марки/модели, мощность, бюджет, страницы и карточки.

Общие условия: [contract.md](contract.md). Текущая стадия: [current.md](current.md).

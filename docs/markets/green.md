# Зелёный угол

| Параметр | Значение |
| --- | --- |
| Источник | Akebono, существующее подключение |
| Условия | Сохранённые параметры склада и расчёта |
| Обновление | Раз в 3 дня |
| Единица публикации | Самостоятельная, отдельно от Японии AJ System |

Источник: `akebono_green` в `apps/web/lib/catalog/collection-controls-schema.ts`; существующий обход получает до 50 записей на страницу.

Сохранять весь завершённый снимок, проверять все страницы и повторяющиеся ID. Неполный ответ не заменяет опубликованный список. Не запускать повторный сбор из-за обновления Японии или другого рынка.

Энциклопедия, цены, город, исходные идентификаторы и ссылки сохраняются. Приёмка включает предложения на странице рынка, в общем каталоге и рекомендациях, фильтры, карточки и очередное плановое обновление.

Общие условия: [contract.md](contract.md). Текущая стадия: [current.md](current.md).

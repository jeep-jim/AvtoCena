Checkpoint: **28.11.2026, Asia/Krasnoyarsk**. Исправляется подтверждённая пользователем новая ошибка Японии: после «до 160 л.с.» → сортировка по цене каталог показывал 0 машин, а при неизвестном полном количестве исчезал счётчик. ## Подготовленное исправление

- Runtime **`20fd18d12b3f5c7aabef860e1b53da0d505dfd64`**, tree **`b3257c801b2b26cc84ec8d37380a2d8ec120b431`**, ветка `fix/japan-price-sort-count-20261128`. Предшественник — принятый B9 `b9e9122b75f4e588088d0241476b18df7f047d96`.
- Точная дельта — **11 файлов**, SHA256 `8e5a3d15adeec0f78c073e982f30fe1a2278b1e6462d2ec81dad13ac12280515`. Pricing `64c6338e0db23c8999096bceefbf113c0136fe15` сохранён; 116 путей накопленной совместимости проверены по точным байтам. Защищённые формулы, CRM и другие рынки новой дельтой не изменены.
- При совместном power-фильтре и сортировке по итоговой цене сырой порядок `FINISH` больше не вытесняет подходящие автомобили из ограниченного чтения. Сортировка рассчитанной цены выбранного города сохранена внутри загруженной страницы и группы известной/неизвестной мощности. Глобальная сортировка всего источника между страницами не заявляется.
- Счётчик показывает подтверждённое точное количество, когда оно есть; иначе — реально загруженное число и явный статус неполного подсчёта. «Показать ещё» увеличивает его, смена query сбрасывает число к новой выборке. Неизвестный total не становится нулём.
- Пустой interrupted/partial/stale ответ сохраняет предыдущие полезные карточки с существующим статусом ошибки. Правила мощности, ручные сведения, энциклопедия, город, source SQL, бюджеты чтения и TTL сохранены.

## Доказательства и следующий шаг

- **1726/1726 controller** и **563/563 native runtime tests PASS**; web/engine typecheck PASS. Реалистичная регрессия с подходящими машинами между двумя группами неподходящих сначала воспроизводила пустую выдачу; обе сортировки и следующая страница теперь проходят. Затем такой же ограниченный live journey должен подтвердить `japanPriceSortPassed` и `japanCountDisplayPassed` вместе со всеми прежними Japan gates.

- Следующее действие: hosted Verify точного controller/runtime → отдельный marker выпуска → проверка фактической установки и живой выдачи. До этого публичное исправление не считается завершённым.

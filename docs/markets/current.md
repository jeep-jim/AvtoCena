## Отказ первой публикации 25.11 в 10:40 по Красноярску — точная причина

[Выпуск 45536536119](https://github.com/jeep-jim/AvtoCena/actions/runs/45536536119) завершился **failure** через 43 мин 24 с. Исходный подготовленный Китай (283188 машин), 12 серверных функциональных проверок, серверная скорость и базовый браузер (390/1280) прошли. Во время расширенной проверки после временного переключения на новый runtime браузерный отчёт `china-browser-details-report.json` показал `stage=model_city_detail`, `code=china_browser_visible_detail_price`, `timeout=false`. Для города Новокузнецк проверены 4442 автомобиля, 24 карточки, совпадение ID и цен каталога. ID и числовая цена страницы прошли проверки; видимый текст цены детали не совпал с сохранённой ценой. **Эту проверку не отключать.**

В отчёте упавшего выпуска было `accepted=false`, `observedPublicRelease=56d6b94fea70457e0ce2b0820596da9972846b90`, `publicationPendingRecovery=true`. Отдельная [read-only проверка №45542353692](https://github.com/jeep-jim/AvtoCena/actions/runs/45542353692) подтвердила `reserved` + `intent=pending` при освобождённой lease. Затем одноразовая [операция №45542584327](https://github.com/jeep-jim/AvtoCena/actions/runs/45542584327), привязанная к точному run/nonce и реальному host rollback proof, успешно перевела состояние в `resolved` и подтвердила старый публичный runtime `56d6b94fea70457e0ce2b0820596da9972846b90`. Новое поколение **не принято**.

**Обнаруженная возможная причина в клиентском коде:** при открытии карточки с явным городом `CitySelector` на mount читает глобально выбранный город и может вызвать новый расчёт; подписка на текущие курсы также могла вызвать непрошенный перерасчёт. Точная клиентская последовательность ещё не доказана и должна пройти отдельный тест. В main внесён целевой фикс: `c8f7c0f` (правило города), `f74ec0d` (закрепление и отсутствие автоматической переоценки), `6ce688a` (передача контекста страницы), `6e47fae` (тест), `381ec5c` (отдельный CI без деплоя). В контроллер `835f812` добавлен диагностический вывод ожидаемой и видимой цены при следующей проверке, без отключения обязательной проверки. **Эти коммиты ещё не являются установленным runtime сайта.** Первичная проверка main №45542018063 указала на расхождение типов старой страницы main с закреплённым новым runtime — изменение страницы main отменено. Точный кандидат исправлен в [ветке `fix/china-detail-frozen-city-20261125`](https://github.com/jeep-jim/AvtoCena/tree/fix/china-detail-frozen-city-20261125) от `38895e53`; [проверка №45542253549](https://github.com/jeep-jim/AvtoCena/actions/runs/45542253549) **успешна** (3 целевых теста и typecheck). Этот результат доказывает только код и типы, **не реальный браузер с полной генерацией**. Перед следующим дорогостоящим выпуском нужен быстрый браузерный preflight точного кандидата с явным городом, другим сохранённым городом и новым курсом, проверяя видимую цену против Oracle. Условие добавлено в [единый план](migration-plan.md).

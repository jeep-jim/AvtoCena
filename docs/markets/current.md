## Подготовленный исправленный кандидат

**077cbb17626ab0c64e7f06db055fef9252ad21c0**, отдельный scope **catalog-japan-completion-v2**, полный diff 19 файлов от принятого 36c7. Родитель 50a660 и прежний 8cc5 не являются retained runtime. Базовый reviewed plan сохраняет 36c7; меняется только successor code-plan.

- Сохранены исправления допустимого scalar PW для редактируемого предварительного расчёта и города из URL. Локальная/ручная мощность и kW приоритетнее; противоречивый hybrid/EV PW не получает расчётного назначения.
- Пустой исходный массив требует точного COUNT после освобождения supplier slot. Только COUNT 0 либо COUNT <= offset доказывает настоящий ноль/конец страницы. Непустые исходные страницы не получают дополнительный COUNT.
- Неподтверждённый пустой ответ не сохраняется и не заменяет полезные строки. Старый empty без доказательства не считается fresh. При отказе — допустимый резерв с настоящей датой и stale либо unavailable.
- Подтверждённый ноль заменяет прежние строки и защищён от возвращения более старых visitor/legacy/partial результатов и гонок. Более новое успешное наблюдение машин снова допускается. Лимит 2 запросов, квоты, IP, 30 минут свежести и 7 дней резерва сохранены.

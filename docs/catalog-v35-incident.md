# Инцидент каталога v35 — 2026-07-29

Эта запись должна быть перенесена в `roadmap.md` после подтверждения production-результата.

## Симптом

- workflow `Catalog source-scale daily #102` был зелёным, но сайт продолжал читать прежний manifest;
- крупная цена карточки показывала `Цена в рублях уточняется`, хотя исходная цена была известна;
- изображения имели ID и metadata, но сохранённый CDN URL не открывался;
- свежая карточка с тем же ID заменяла retention-копию и теряла ранее накопленные изображения;
- Грузия отсутствовала, Кыргызстан содержал две карточки;
- маршруты AUTO.GE и Mashina не соответствовали текущим массовым листингам.

## Причины

1. Web enrichment не восстанавливал `currencyRate/sourcePriceRub` для старой опубликованной generation.
2. Публичная карточка доверяла сохранённому CDN URL вместо стабильного same-origin image proxy.
3. Rebuild объединял fresh и retained только как разные записи; совпавший fresh ID вытеснял retention-галерею.
4. Приоритет до 6 млн ₽ проверял только готовый `totalRub`, игнорируя рублёвый эквивалент source price.
5. Рабочие листинги находятся на `https://www.auto.ge/en/index.html` и `https://www.mashina.kg/search/all/`.

## Исправление

- `live-business-pricing.ts`: восстановление курса и `sourcePriceRub` перед публичным показом;
- `image-quality.ts`: URL `/api/catalog/images/{imageId}` для всех публичных карточек;
- `catalog-rebuild-source-shard.mjs`: merge retention + fresh, накопление галереи до 30 и рублёвый приоритет;
- `regional-live-overrides.ts`: актуальные маршруты AUTO.GE, Mashina и Turbo;
- тесты и CI закрепляют все четыре регрессии.

## Definition of Done

- новый `generationId`;
- все 7 рынков в manifest;
- крупная цена в рублях на карточках;
- исходная валюта только второй строкой;
- `maximumImages > 1`, предпочтительно до 30;
- Грузия и Кыргызстан имеют реальные карточки;
- брендовые и модельные SEO-страницы не изменены;
- production workflow не считается подтверждённым только по зелёному значку.

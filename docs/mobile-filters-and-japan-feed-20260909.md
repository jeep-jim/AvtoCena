У фильтра удалено JavaScript-переключение вверх/вниз, конфликтовавшее с CSS position:static. На мобильной ширине списки раскрываются вниз в потоке панели. Убрана обработка каждой прокрутки и обход всех узлов каталога; MutationObserver реагирует на изменения фильтров. Повторная запись одинакового textContent кнопки закрытия больше не создаёт цикл наблюдения. Зависимые варианты фильтра используют один отложенный обработчик вместо отдельных таймеров на каждое событие. Тяжёлое размытие фона убрано. Фон фиксируется с сохранением scrollY и восстановлением после закрытия. На телефоне router.replace выполняется после закрытия панели, а не после каждого выбора; десктоп сохраняет автоприменение.

## Япония: проверенные варианты

Проверка страниц и формы 09.09.2026. Это предложения поставщиков, не результат испытания оплаченного доступа.

**AVTO.JP / AJ System — основной кандидат.** [Форма заказа](https://avto.jp/order?enter=) в живом браузере: базовый пакет Japanese Auctions + Statistics3months при выбранном API —159USD/месяц; расширенный API included + Month of production + Electronic Office —214USD/месяц. Выбирался только тариф, заявка не отправлялась. Для нашего продукта предпочтителен расширенный вариант из-за месяца выпуска, если данные действительно заполнены. Кнопка REQUEST открывает путь заявки; оплата картой, автоматическое списание и мгновенная активация публично не подтверждены. Полугодовая/годовая скидка заявлена на странице; до проверки не оплачивать долгий срок.

[Документация API](https://avto.jp/api?enter=): SQL-запросы с XML/JSON, отдельная таблица stats; допускается собственный дизайн и логика. Для статистических выгрузок указано обновление раз в24часа, для текущих аукционов —30минут. Есть примеры получения всех фото поID. Поставщик рекомендует исключать USS у анонимных пользователей; чистые фото требуют отдельного согласования, дополнительные фото TAA — баланса. Публичные примеры API используют HTTP: перед передачей нашего ключа нужен подтверждённый HTTPS endpoint. Запросы с примерными кодами доступа не выполнялись. Наличие точной 30-минутной мощности гибридов/EV и полнота даты производства не подтверждены.

**Prestige Motorsport — бесплатный резерв, не универсальный API.** [Поиск](https://prestigemotorsport.com.au/auctions/) открывается публично и предлагает Past3months; для цен рекомендует Non-USS only, так как цены USS не показывает. ## Подключение к АвтоЦена после получения доступа

Это проект интеграции, не заявленная готовая интеграция:

1. Серверный адаптер читает stats по дате/курсору, хранит исходную запись и источник. Ключ только в секретах сервера; браузер не обращается к провайдеру напрямую. Частоту обновления согласовать с фактическими лимитами API; для статистических dump ориентир документации — сутки.
2. Проверяем на образцах статус SOLD и документированное поле hammer/final price в JPY. START, ненулевой FINISH без доказанного SOLD, несостоявшиеся/отменённые торги не принимаем как состоявшуюся продажу. Идентификатор = провайдер + аукцион + дата + лот. Нужен образец схемы API, чтобы подтвердить названия/единицы полей.
3. Фото и аукционный лист связываются с тем же лотом; проверяем права показа/кэширования, срок ссылок и ограничения USS/TAA. Нельзя обещать полную галерею только на основании оплаченного API.
4. Финальная цена идёт как sourcePriceJPY в наш движок, с активной версией JapanCRM и нашим курсом. Калькулятор поставщика не подменяет наш. Подтверждённый месяц/день производства используется в возрасте; registration year не превращается в production month. Недостающая мощность остаётся вопросом наших подтверждённых источников.
5. Проданный лот отображается как «Завершённые торги / пример стоимости», а не доступный к покупке автомобиль. Карточка, фильтры, галерея и структура расходов остаются нашими; обращение клиента — подбор аналога. Историческая цена продажи и современный ориентир ввоза должны иметь разные даты/подписи.
6. До включения: сверить выборку с экраном поставщика, финальную цену и статус, фото и лист, номиналы валют, даты, дубли, пагинацию, повторное обновление, пропуски и старые лоты. Продвигать новую generation только после общего каталожного допуска; старую сохранять при сбое.

Практический следующий шаг покупки: открыть форму AVTO.JP, выбрать только расширенный пакет API included214USD и API. Получить подтверждение stats/SOLD-финальных цен, HTTPS, лимитов, публичного показа фото и способа регулярной оплаты. Затем первый месяц и пробная интеграция. Мгновенное подключение в пару кликов до этих проверок не обещаем.

# Память публикации Китая · 26.09.2026

Причина подтверждена журналом [задачи 108353360697](https://github.com/jeep-jim/AvtoCena/actions/runs/36215075427): `JavaScript heap out of memory`. Лимит heap 12480 MiB с учётом накладных расходов V8; свободная RAM в начале 14451 MiB. Ошибка не относится к ёмкости Object Storage.

Для Китая лимит Node увеличен с 12 до 24 GiB, на одноразовом runner создаётся 24 GiB swap. Параллельность подготовки и чтения снижена с 4 до 2, чтобы уменьшить пик. Остальные рынки, расписание, расчёты и защита от потери каталога сохранены. Повторная публикация использует готовый артефакт 36215075427 без повторных обращений к источникам. Успех подтверждается только итогом новой задачи публикации.

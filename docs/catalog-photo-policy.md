# Catalog photo policy

The catalog accepts an offer with two credible source-bound photos, but the collector continues toward thirty when the source exposes them.

Production high-volume crawls prefer direct source URLs. Binary caching is a fallback mode, not the default storage model. Obvious banners, campaigns, thumbnails, placeholders and marketing assets are rejected by URL evidence.

Cover ordering must follow source-specific vehicle-photo metadata where available. The system does not claim that URL heuristics can semantically distinguish exterior, interior and arbitrary advertising artwork on every site. Sources without reliable photo-role metadata must remain fail-closed rather than inventing an exterior classification.

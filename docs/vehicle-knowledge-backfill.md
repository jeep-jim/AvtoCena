# Vehicle knowledge coverage

The import-oriented knowledge base covers only vehicles from 2011 onward.

Processing order:

1. Models present in live catalog offers.
2. Vehicles 0-6 years old.
3. Vehicles 7-10 years old.
4. Remaining vehicles 11-15 years old.

Every canonical make/model already exposed by the public catalog must eventually have either verified variants or an explicit source-status record. Unknown power is never guessed. Model/generation media remains separate from listing-bound vehicle photos and must retain source URLs.

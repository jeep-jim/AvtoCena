## Что нужно от поставщика

Поддерживаемый способ получить содержимое страховой истории и осмотра через оплаченный API с точной привязкой к ID/LOT: JSON либо HTML отчёта, включая отметки осмотра/схему, расшифровку полей и отсутствующих значений. Сейчас history/inspection в проверенных ответах содержат только URL; страница tru.ru лишь встраивает Encar. Также требуется подтвердить поле свободного описания продавца отдельно от Equipment и значения LOT REMOVED. Достаточно разрешённых примеров по одному автомобилю с событиями и без событий; полный импорт не нужен.

## Условия завершения

Реальный нормализованный ответ → русские проверенные значения → схема только из подтверждённых отметок → API и тесты неверного/пустого ответа → live проверка опубликованного SHA и сохранённых performance gates. До этого не сливать runtime draft и не заявлять подключение отчётов.

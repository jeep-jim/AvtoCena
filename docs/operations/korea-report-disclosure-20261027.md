# История и осмотр Кореи — 27.10.2026

PR1557 реализует просмотр оригинальных отчётов по поддержанным поставщиком ссылкам, а не извлечение данных из защищённой страницы.

## Подтверждённый источник

27.10 Михаил подтвердил: history/inspection возвращают рабочие ссылки; tru.ru — разрешённая анонимная обёртка. Посетитель может открыть её в новой вкладке или iframe и самостоятельно пройти проверку. Владелец передал скриншоты открытых страховой истории и документа осмотра. Для предоставленной ссылки tru.ru получен HTTP200 и iframe Encar inspectionViewNew с carid42514287. Это не приёмка нашего опубликованного интерфейса и не доказательство доступности каждого отчёта каждому посетителю.

Предыдущий автоматический браузерный отказ40446685949 не доказывал недоступность данных людям. Старое требование получить JSON до подключения просмотра оригинала неверно; для русского перевода содержимого нужен отдельный разрешённый способ обработки документа. Корейский iframe не объявляется русским отчётом. Автоматическое решение CAPTCHA, обход ограничений и загрузка отчётов серверным скрейпером не реализуются.

История проверок сохранена:40445502822/40445773996 — ответ history/inspection состоит из пары URL с привязкой к LOT;40455767266 — два текущих ID, ссылки строками, один ajax LOT REMOVED и один без него. LOT REMOVED в ajax не означает отсутствие обоих внешних отчётов и не используется для удаления машины.

## Реализация

- Кнопка «История и состояние» остаётся рядом с «Все характеристики» на desktop, под характеристиками на mobile. Модуль панели загружается по нажатию.
- «Страховая история» и «Осмотр автомобиля» раскрываются отдельно. До выбора конкретного отчёта нет API-запроса или внешнего iframe. Ошибка одного блока не сбрасывает другой, карточку, цены или фото.
- API делает один ограниченный запрос к купленному фиду для указанного ID и вида отчёта. Принимает tru.ru/korea/token только вместе с точным Encar LOT/видом из того же ответа; чужие домены, произвольные перенаправления, неверный LOT не проходят. Сервер не загружает содержимое Encar/tru.ru.
- Существующие owner switch, реальные visitor IP, выбор кластера, учёт использования сохранены. Нет автоматических повторов/сборщиков. Тайм-аут20с, тело≤2MiB, до2 одновременных запросов и8 ожидающих, cache≤128/512KiB/5мин с ключом visitor+ID+LOT+kind. Отказ visitor останавливает новые запросы на5мин; успех другого IP не используется для обхода отказа.
- Оригинал открывается в отдельном iframe с ограничениями sandbox. Ссылка «Открыть в новой вкладке» доступна независимо от загрузки iframe. Нельзя определить успешность внешнего отчёта по событию load: оно может означать капчу/отказ, поэтому готовность содержимого не заявляется.
- Русские кнопки, загрузка, ошибки и инструкции; документы остаются на корейском, это явно указано. Нет выдуманных сведений об отсутствии ДТП/ремонта. Перевод документов и структурированная схема состояния остаются отдельным незавершённым пунктом.

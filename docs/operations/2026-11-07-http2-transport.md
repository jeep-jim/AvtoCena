# HTTP/2 — ограниченная транспортная оптимизация

Основание: владелец 07.11.2026 запросил восстановление и оптимизацию каталога без изменения его бизнес-логики. В сравнительном браузерном аудите 42333928729 у ZMA зафиксирован HTTP/2, у АвтоЦены HTTP/1.1. Это наблюдаемое отличие, не доказательство единственной причины задержек.

Ветка fix/catalog-http2-20261107 проверяет только преобразование конфигурации. Применение разрешено только из main после слияния проверенного PR, с явным marker catalog-http2.json и существующей защитой environment regcloud-staging. Первый запуск 42336633105 закончился до выполнения шагов; сервер этим запуском не менялся. Причина отказа из доступных метаданных не установлена, защита environment не отключалась.

Перед применением проходят тесты преобразования, проверка модуля nginx, backup и nginx -t. Изменяются только существующие TLS listen/http2 directives. Общий runtime-lock; graceful reload; проверяются ALPN h2 и неизменные releaseSha/calculationVersion в health. При неуспехе config восстанавливается, проходит nginx -t и reload.

Не меняются upstream, адрес посетителя, заголовки авторизации, кеширование, сертификаты, приложение, данные, сборы или расчёты. Публичный HTML с авторизованными/дилерскими данными не переводится в общий cache. HTTP/2 не является исправлением supplier visitor_restricted, полноты фильтра мощности или неизвестных характеристик.

До получения журналов применения статус установки не подтверждён. Реальную скорость после reload измерять отдельно; VPN-паритет не проверен.

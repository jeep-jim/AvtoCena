# Память публикации: 23 ноября 2026

## Подтверждённая причина остановки

[Korea 45041812628](https://github.com/jeep-jim/AvtoCena/actions/runs/45041812628/job/137280315531) и [45077320093](https://github.com/jeep-jim/AvtoCena/actions/runs/45077320093/job/137409157390) упали после storage preflight, до `before_persist`, с JavaScript heap OOM. Workflow задавал `--max-old-space-size=12288`; probe показал полный heap 12480 MiB. Около 10 GB в последнем GC — потребление, не обнаруженный отдельный потолок 10 GB. Доступная физическая память в момент fatal не измерена.

На этом участке publisher повторно читает текущую Корею для snapshot guard, затем накапливает полные принятые срезы соседей. Дочерние serving/pricing builders с отдельными потолками 3072/6144 MiB ещё не запускались. Конкретная allocation-строка без профиля не установлена.

[UAE 45076401719](https://github.com/jeep-jim/AvtoCena/actions/runs/45076401719) остановился на `serving_read_model_byte_bound`: потоковый JSONL был искусственно ограничен суммарными 2 GiB. Финальный отчёт сохранил предыдущий manifest.

## Принятое исправление

- Тяжёлые процессы запускаются через `scripts/run-node-with-resources.mjs`; фиксированные 3/6/12/24 GiB из затронутого пути снимаются. Каждый запуск пересчитывает доступную RAM и проверяемый свободный swap. Полный V8 heap проверяется внутри самого процесса; конфликтующие прежние memory flags удаляются, остальные параметры сохраняются.
- Проверка swap учитывает cgroup v2 и предков; при неполной видимости используется только RAM с явной причиной. Общий publication job получает ту же дополнительную swap-область одноразового runner, которая ранее была только у Китая.
- `latestTargetRows` освобождается сразу после прежней проверки snapshot; потреблённые Map/Set очищаются после последнего использования. Записывается память и фаза чтения каждого сохранённого рынка.
- JSONL передаётся потоково без общей квоты 2 GiB/миллион строк. Точные SHA-256, байты и количество строк проверяются при полном чтении. Ограничение отдельной некорректной строки и проверки runtime, источника, расчёта, lease/CAS сохранены.
- Повтор Korea берёт только полностью подготовленный intake `45077320093/1`, source `c90dea655470d2970f5f22cc7d7f98c086874738`, artifact `14779553850`. Оригинальный producer/attempt, успешные шаги подготовки, имя, размер, digest, срок и report проверяются до публикации. Новый сбор не запускается.

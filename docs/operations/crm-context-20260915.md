ENV-файл только для системного пользователя, не в git. Перед запуском установить Node 24, зависимости npm ci, readonly checkout; пользователь avtocena-bot. Включение unit и проверка журналов выполняются после настройки хоста.

В группу выводятся ссылки всех выбранных автомобилей. Если лот исчез или чтение каталога завершилось ошибкой, ссылка сохраняется без выдуманных характеристик.

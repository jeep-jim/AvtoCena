# Япония — AJ System / avto.jp

> Актуальный итог: 17.10.2026 задача повторно открыта владельцем; полная работоспособность не подтверждена. Активная граница Японии — 2008 включительно. История прежней приёмки ниже не является текущим статусом. Новые Китай/Корея: см. `ajes-china-korea.md`.

## Состояние на 15.10.2026

Владелец сообщил об оплате Японии и передал доступ. Выполнены четыре ограниченных запроса к указанному поставщиком `87.242.72.57/api/`: по одному лоту main и stats, один подходящий результат stats и его полная карточка по ID. Получены JSON-ответы; у полной карточки есть SERIAL, INFO и 12 изображений вместо двух в списке. Коммерческие ответы и пароль в репозитории не сохраняются.

Подготовлены клиент, построитель запросов, ограничитель, выключатель и закрытый POST `/api/crm/ajes` для проверки владельцем. **Публичный каталог ещё не подключён.** Общий запрет старых японских источников и переход на Зелёный угол пока сохранены. Это промежуточный этап, не готовый выпуск.

## Контракт

- Документация: https://avto.jp/api?enter ; пример: https://ajes.com/api/sql2json . PHP-пример не устанавливается: он выводит URL с паролем и принимает SQL-фрагменты из пользовательских параметров. Реализация Next.js использует закрытый набор полей.
- Серверный секрет: `AJES_API_PASSWORD`. Никаких NEXT_PUBLIC, query-параметров собственного сайта, публичных файлов или логирования URL поставщика. Сейчас секрет в рабочем окружении не установлен этой сессией.
- Endpoint фиксирован на выданном поставщиком HTTP-адресе, путь `/gzip/` согласно дополнительной памятке. Проверен живой сжатый ответ по ID: HTTP200, стандартный gzip, идентичность совпала, 12 фото. HTTPS поставщиком в письме не указан и не проверен; защищённость транспортного участка не заявляется.
- Источник `ajes_japan_feed` по умолчанию выключен. Старые настройки получают только этот новый выключенный пункт; отсутствие старых переключателей остаётся ошибкой. Выключатель рынка Япония также обязателен.
- POST доступен только владельцу с разрешённым Origin. Nginx переписывает X-Real-IP на remote_addr в существующих скриптах конфигурации.
- Поиск: table (stats по умолчанию, либо main), make, model, chassis, lotNumber, yearFrom/yearTo, mileageFrom/mileageTo, engineFrom/engineTo, page/pageSize. Неизвестные поля, произвольный SQL, некорректные числовые значения отвергаются. Максимум 48 строк за запрос. Нет сканера всей базы, обхода страниц в фоне или автоматических повторов.
- Карточка: только table и id. Полная информация запрашивается именно по ID, идентичность ответа проверяется.
- Япония 2010+, USS исключается. Для stats принимаются только Sold с положительным FINISH. FINISH — итог торгов в JPY; START не заменяет итог; AVG_PRICE не заменяет FINISH. Main хранит стартовую цену отдельно и не объявляется проданным.
- PW, PRIV, KPP, FUEL сохраняются как исходные значения для проверки. Не выводятся догаданные л.с., топливо, привод, дата производства или цена под ключ. В одном реальном ответе PRIV содержал несколько вариантов. INFO не интерпретируется как надёжная спецификация без отдельного разбора и проверки.
- Изображения: прямые HTTPS URL разрешённых доменов; small `&h=50`, medium `&w=320`, оригинал отдельным URL. Ничего не скачивается на сервер. Первый файл только полной карточки помечается как аукционный лист.
- Кэш: 30 минут, максимум 300 запросов/16 МиБ на процесс, объединение одинаковых запросов, не более двух одновременных загрузок. Выключатель проверяется и при чтении кэша. Ошибки не превращаются в пустую успешную выдачу.
- Только принятые полные карточки, открытые по ID, сохраняются в закрытом хранилище `catalog/partner-cache/ajes/{table}/{id}.json`. Списки не сохраняются в базу. Сохранённая карточка переиспользуется до30мин, затем запрашивается заново; это пока не SEO-индекс. Массовая индексация, скрытие дат и скачивание фото из памятки не включены.
- Суточная защита: общий для процессов счётчик с условной записью, отдельные пулы main/stats. Консервативный предел 19 000 запросов за скользящие 25 часовых корзин, запас относительно заявленных 20 000. Неудачный запрос также расходует резерв. Заголовки API-Counter/API-Limit/API-Rest доступны владельцу в ответе; значения относятся к моменту загрузки, при кэше не являются текущими.
- Секреты и исходный текст ошибок поставщика не возвращаются. Redirect запрещён; тайм-аут 20 с, ответ до 2 МиБ.

## Примеры закрытой проверки

Только после настройки секрета и включения выключателя:

```json
{"table":"stats","make":"TOYOTA","model":"COROLLA","pageSize":24}
```

Далее передать полученный id в `{ "table": "stats", "id": "..." }`. Успешный ответ не публикует карточки и не меняет существующие объявления.

## Что требуется для запуска

1. Передать секрет в приватное окружение REG.RU, проверить путь сохранения при последующих релизах; не помещать его в публичный GitHub. Проверить закрытый endpoint на сервере.
2. Добавить DNS-записи, которые выдал Михаил: `auc A 87.242.72.59`, `auc AAAA 2a00:15f8:c001:3:225:90ff:fed4:7912`. В этой сессии DNS не изменён. Локальное разрешение auc.avtocena.com завершилось ошибкой; это не проверка авторитетной зоны.
3. Проверить http://auc.avtocena.com/currency после DNS. Письмо требует обновления раз в час. Не заменять им курс действующего расчётного движка без проверки формата и назначения.
4. Встроить отдельный живой источник в каталог, карточку, справочники и счётчики. Разрешить только новый источник, не снимать запрет старых данных. Учесть редакторские скрытия, неизвестные характеристики, разрешённую полную массу и поведение при недоступности API.
5. Сохранить честную работу бюджета/сортировки: поставщик пока не даёт точную цену под ключ. Нельзя фильтровать только 24 полученных строки и объявлять их полной выдачей рынка; нельзя обходить всю базу ради бюджета. Поведение живого поиска и локального кэша требует реализации до включения в общий каталог.
6. Проверить мобильную/десктопную выдачу, полный лот, фотографии, расчёт, фильтры, отказ источника и сохранность Зелёного угла. Только затем выпуск и подтверждение releaseSha.

Проверено локально: 16 тестов (новый клиент/лимит/контракт, gzip с пределом распаковки, сохранение только открытых карточек и существующие выключатели), TypeScript. Публичный интерфейс, DNS, секрет на production и рабочая публикация этой сессией не проверены.

## Публичное подключение (15.10.2026)

- `/cars?market=japan`: поиск в stats по марке/модели, году, пробегу, объёму, кузовному коду и номеру лота, по 24 записи с переходами страниц. Общий счётчик всего фида не заявляется; массовой выгрузки нет.
- Новый формат ID `ajes-stats-<ID>` открывает существующую карточку/калькулятор через отдельный запрос полной записи. Выведены только цена завершённых торгов и её пересчёт по существующему курсу ЦБ. Доставленная стоимость не подменяется этой ценой. Неоднозначные характеристики остаются редактируемыми.
- Итоговый бюджет, мощность, топливо и другие не поддержанные источником фильтры пока не реализованы: при их наличии выдача не запускается, интерфейс предлагает применить доступные условия. Это ограничение первой публичной версии, а не точный подбор по итоговому бюджету.
- `/crm/site` → «Обновление каталога · парсеры и фиды» → «Япония»: владелец вводит API-пароль. Endpoint `/api/crm/ajes/settings` проверяет один лот, сохраняет AES-256-GCM значение в закрытом `integrations/ajes/config.json` с ключом на основе AUTH_SECRET. GET возвращает только признак настройки. После сохранения владелец включает `ajes_japan_feed`. Выключенный рынок не обходится.
- Серверное окружение AJES_API_PASSWORD остаётся альтернативой при отсутствии сохранённой настройки. Пароль никогда не отправляется в публичную страницу.
- Обычные фотографии — средние прямые ссылки, оригинал запрашивается при увеличении. Аукционный лист отдельно помечен и сохраняет исходный размер. Формулы двигателя/таможни и старый запрет источников не изменены.
- DNS auc A/AAAA подтверждены скриншотом владельца; HTTP currency отвечает200. Курсы этого endpoint не заменяют действующий официальный пересчёт: единицы и контракт часового обновления требуют отдельной сверки.


## Уточнение поставщика 16.10.2026: топливо

Михаил через владельца подтвердил: топливо в текущем API называется `TIME`. Чтение лотов и SQL-фильтр топлива используют `TIME`; `FUEL` оставлен только как резервный вариант чтения старого формата. Коды P/D/E/H/HE/L/C сохраняют документированное значение. Неизвестный или составной код не становится подтверждённым топливом. Источник semanticEvidence указывает фактическое поле. Старый нормализованный кэш без schemaVersion2 обновляется при следующем запросе пользователя; при отказе поставщика остаётся прежняя карточка с честными пропусками. Массовой перезагрузки нет. Уточнение TIME не разрешает неоднозначность мощности PW.


## Уточнение PW и поручение владельца 16.10.2026

По скриншоту переписки поставщик подтвердил: PW в лошадиных силах, использовать первое значение, данные примерные; через1–2недели планируется одно типичное, всё равно примерное значение. Владелец разрешил первый вариант для автоматического предварительного расчёта с ручной корректировкой. Он заполняет только редактируемый черновик калькулятора, а не подтверждённую мощность объявления. Заголовок цены и пояснение обозначают предварительность; ссылка на расчёт сохраняет выбранные параметры. Это не 30-минутная мощность и не подтверждение вида гибрида.

По отдельному поручению владельца полный SERIAL выводится в характеристиках AJES как номер кузова, KUZOV как код кузова. Цвет, оснащение, обозначения КПП/привода, место и данные аукциона сохраняются при наличии. В просмотренных API-ответах нет подтверждённого URL аукциона: название выводится, но ссылка не выдумывается и API-адрес с ключом не публикуется.


## Отказы отдельных посетителей и общий кэш — 16.10.2026

Общий кэш AJES принимает только свежие успешные ответы. Резервный старый ответ после отказа поставщика хранится в отдельном кэше по фактическому IP посетителя и SQL на30мин. Незавершённые запросы разных посетителей также разделены: отказ первому не должен лишать второго собственной попытки обновления. Успешный свежий ответ снова используется общим кэшем без дополнительных запросов. Общий бюджет памяти16МиБ разделён8+8, параллельность2 сохранена. ПодменыIP и обхода отказа источника нет.

Выбранные исходные ENG_V/PW/TIME/FUEL сохраняются приватно с ID и временем конкретного успешного ответа списка/детали. Публичное преобразование удаляет диагностические поля. Отсутствие нового исходного ответа и пустые значения в успешном ответе — разные состояния; ни одно не позволяет выдумывать мощность или топливо.

### Как подключено

- Публичный интерфейс остаётся нашим: каталог, карточка, калькулятор, мобильная навигация, фильтры, похожие автомобили. AJES — адаптер данных; старый ProAuctions не возвращается. Зелёный угол — самостоятельный источник наличия, его CIF нельзя смешивать с FINISH завершённых аукционов.
- Живые запросы идут сервером к фиксированному `/gzip/`, секрет только в закрытой конфигурации. Поставщику передаётся фактический IP посетителя. bot2/visitor_restricted — отказ источника; VPN может влиять на его решение. Подмена IP не является исправлением. Сохранённые подходящие ответы позволяют показывать ранее полученные данные.
- Основная выдача — stats, завершённые проданные лоты с положительным FINISH, Япония2008+ (обновлено указанием владельца17.10), исключение auction_type=1 и известных тяжёлых семейств. Правило владельца: не показывать грузовики/автобусы с разрешённой полной массой>3500кг; отсутствие массы не позволяет выдумывать её. Kei не исключаются целиком.
- Полная запись читается по точному ID; список не заменяет полный ответ. KUZOV — код кузова, SERIAL — номер кузова, ENG_V — объём. TIME — топливо, FUEL только старый резерв. PW — примерные л.с., первое допустимое число для редактируемого предварительного расчёта. Цвет COLOR, оснащение EQUIP, привод PRIV, КПП KPP/KPP_TYPE, место TOWN, сведения об аукционе выводятся при наличии. Составные/неизвестные характеристики не становятся подтверждёнными.
- Топливо: P бензин, D дизель, E электричество, H/HE гибрид, L LPG, C CNG. Пустой TIME остаётся пустым. PW не заменяет сертифицированную30-минутную мощность гибрида/EV. Сохранённые ручные настройки расчёта имеют приоритет.
- Поддержаны марка, модель, код кузова, номер лота, год, пробег, объём, топливо, КПП, привод, оценка; агрегаты количества/моделей и пагинация. Код кузова важен для поиска модификации, но не разрешает автоматически утверждать4WD. Сортировка цены в SQL использует FINISH, а не индивидуальный итог под ключ.
- FINISH — цена завершённых торгов в JPY; START/AVG_PRICE её не заменяют. Итог под ключ считает существующий движок при достаточных параметрах. Наличие предварительной мощности должно оставаться видимым; неизвестные поля можно заполнить вручную. Счётчик stats — записи торгов, не доказанное количество уникальных доступных автомобилей за ровно90дней.
- Фото только прямыми разрешёнными ссылками; оригинал для увеличения, аукционный лист отдельно. Подтверждённый URL исходного аукциона выводить при наличии; имя аукциона не позволяет придумывать ссылку. Массовое копирование японских фото в наше S3 не включать: условия поставщика отличаются от других рынков.
- Кэш свежего результата30мин, общий успешный кэш отделён от резервного по реальному посетителю. Параллельные отказы разных посетителей не объединяются. Сохраняются полные открытые карточки и ограниченные слоты запросов в приватном хранилище; раннее описание «списки не сохраняются» выше относится к первой версии. Сохранённый ответ может использоваться резервно до7дней согласно проверкам клиента; это не доказательство актуального наличия.
- Общий бюджет памяти16МиБ (8+8), параллельность2, тайм-аут20с, максимум2МиБ распакованного ответа. Суточная защита19000 в25часовых корзинах относительно заявленных20000. Сохранять выключатели/квоты даже для новых путей доступа; не создавать фонового обхода всей базы.
- Диагностика сохраняет выбранные исходные ENG_V/PW/TIME/FUEL с ID/временем приватно; публичный DTO их удаляет. Логировать безопасный тип ошибки, идентичность и время, но не секрет/URL с кодом/полный bot-ответ.

## Уточнение интерфейса и бюджета счётчиков — 17.10.2026

По замечанию владельца удалено дополнительное поле «Номер кузова» из фильтров. Остаются «Код кузова» (KUZOV) и «Номер лота» (LOT); SERIAL сохраняется в характеристиках и совместимости старых ссылок.

После исчерпания 19000 попыток обычный поиск не получает новые попытки. Только aggregate=count может использовать до20 попыток из прежнего запаса1000: общий предел19020 в тех же25часовых корзинах, без сброса учёта. Остаётся980 до заявленного поставщиком предела20000. Квота общая между процессами; ошибки тоже расходуют попытку. Пауза после исчерпания обычной квоты отделена от счётчика, запрет по фактическому IP общий и не обходится. Свежий успешный счётчик сохраняется в защищённом слоте. Эта мера не гарантирует ответ поставщика и не восстанавливает полноценный поиск при исчерпании обычного бюджета.


## Марки и похожие модели — 17.10.2026

Список марок запрашивается отдельным агрегатом marka_name,count(*) с пагинацией500, независимо от первой страницы автомобилей и справочника моделей. Числовой ответ поддерживает count(*)/total/count и позиционный TAG1. Справочники имеют отдельные ограниченные слоты кэша, общий список марок — защищённый ключ. Резерв20 попыток теперь общий для count и makes; потолок19020 не увеличен. Обычные списки/детали/модели остаются в19000. После выбора марки модели запрашиваются в рамках этой марки, а не повторным обходом полного справочника.

После отказа живого списка разрешён резервный точный поиск сохранённых лотов по make/model, дополнительно к KUZOV/LOT/SERIAL. Все условия проверяются совместно, неподдерживаемые фильтры и страницы после первой не подменяются частичной выборкой. Частичные данные не получают выдуманного total. Это даёт карточке возможность показать уже известные автомобили той же модели, сохраняя возраст, исключение тяжёлой техники и отсутствие текущего ID в рекомендациях. Не гарантия полноты исходного фида.

При отказе справочника резерв названий собирается из всех сохранённых страниц, с проверками возраста, статуса и тяжёлой техники. Он не выдаёт число сохранённых строк за количество машин в фиде. Диагностика17.10 обнаружила17марок, но только один сохранённыйNissanSylphy: карточку нельзя рекомендовать саму себе. Отдельный ответbot2 без пробела и с начальным пробелом также классифицируется как запрет посетителя, чтобы не повторять запросы после такого отказа.

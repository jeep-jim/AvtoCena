# Открытые технические данные ASTRA

Источник: [официальный каталог ASTRA IVZ](https://opendata.astra.admin.ch/ivzod/).
Разрешение владельца на массовый импорт открытого каталога записано в `AGENTS.md`
и `roadmap.md` за 23.10.2026. Полные исходники хранятся в настроенном REG object
storage. В публичный Git попадают код, схемы процесса и проверочные отчёты;
сырые выгрузки туда не добавляются.

## Воспроизводимая загрузка

`source-plan-2026-10-23.json` фиксирует URL, размер, ETag, дату изменения и SHA256
каждого выбранного файла. Команда:

```bash
python scripts/encyclopedia/download-astra.py \
  docs/encyclopedia/astra/source-plan-2026-10-23.json \
  --output-root /tmp/astra-import --workers 4
```

Файлы сохраняются в `raw/` с исходной структурой каталогов. Проверенный манифест
пишется в `download_manifest.json`. Поле `complete` относится к отдельному файлу:
полнота всего набора требует совпадения множества путей с планом и успешного
завершения команды. Только после проверки всего набора создаётся
`download_complete.json` с числом и суммарным размером файлов, SHA256 плана и
манифеста. При обрыве следует повторить ту же команду: завершённые файлы
сверяются по SHA256, незавершённые блоки продолжаются по HTTP Range. Максимум
четыре параллельных запроса; размер блока — 8 МиБ. Изменение опубликованного
объекта по отношению к плану останавливает импорт до явного обновления плана.

Загрузчик допускает HTTPS только на `opendata.astra.admin.ch/ivzod/`, проверяет
перенаправления, длину, ETag, Content-Range и контрольную сумму. Подменённый,
обрезанный или изменившийся файл не получает статус завершённого источника.

## Что входит

| Раздел | Данные | Назначение |
| --- | --- | --- |
| 3000 | Полный eDatenblatt CSV и XLSX с описанием полей | Точные type/variant/version, CoC, раздельные характеристики ДВС и электромотора |
| 4000 | TAS Automobil CSV, Emission CSV, полный JSON ZIP и схема | Технические одобрения, исходные подробности и поля выбросов |
| 2000 | TG-Automobil, emissionen, verbrauch и полная таблица одобрений | Более ранние одобрения и дополнительные технические поля |
| 2000 | egnr и tarmeg68 | Связи европейских одобрений и идентификаторы двигателей |
| 1000 | Официальный справочник кодов | Значения кодов категорий и характеристик |

К исходникам приложены официальные описания полей и связей. Немецкая и французская
выгрузки одних данных не импортируются дважды. Разложенные developer-таблицы,
чьи поля уже входят в TG-Automobil, emissionen и verbrauch, не дублируются.
Исторические сканы до 1995 года, статистика регистраций/владельцев, контрактные
выгрузки, правила обслуживания и справочники тюнинга не подменяют технические
записи модели. Конкретные исключения и основания перечислены в плане.

## Проверка полноты JSON

`tas-archive-completeness-2026-10-23.json` фиксирует сравнение архива с официальным
каталогом `4100-json-Files/`: 228 520 JSON, без пропусков, лишних файлов и
повторяющихся имён. CRC всех файлов проверены. Их общий размер после распаковки —
9 251 486 561 байт, поэтому обработчики читают JSON непосредственно из ZIP и не
разворачивают весь архив на диске.

Это число документов одобрений, а не число моделей, готовых расчётов или
совпадений с автомобилями АвтоЦены. Полнота официального архива не доказывает
охват всех мировых модификаций.

## Границы применения характеристик

Файлы являются источниками доказательств. Применение к каталогу отдельно требует
точной технической идентичности и сохранения прежних ручных правок, ревизий и
истории. Даты изготовления и регистрации не становятся модельным годом.
Максимальная, системная и 30-минутная мощности сохраняются раздельно; неизвестные
и противоречивые значения не вычисляются из названия автомобиля или пиковой
мощности. Успешная загрузка не означает публикацию новой расчётной базы.

## Перенос в постоянную энциклопедию

Одноразовый workflow `encyclopedia-astra-import.yml` читает явный маркер
`.github/market-runs/encyclopedia-astra-import.json`. Расписания и автоматического
повторного запуска нет. Он использует существующее окружение и закрытое хранилище
REG; конкурирующие исследовательские записи сериализуются общей группой workflow.

В режиме `preview` проверяется SHA256 всего плана источников. Каждый исходник
сразу после проверки сохраняется неизменяемым объектом
`knowledge/astra/v1/sources/<sha256>/<filename>`. Квитанция по URL/ETag/размеру
позволяет восстановить уже перенесённый файл после прерывания, сохраняя проверку
содержимого. Полнота принимается только после сверки всех путей и суммарных байт.

Три основные таблицы обрабатываются потоково. Технические группы отделены от
дополнительных конфигураций; подробности сохраняются с точными ссылками в сжатых
JSONL, затем в неизменяемом корпусе REG. Дополнительные TAS JSON, расход, выбросы,
европейские одобрения и коды двигателей сохраняют селекторы версии и коробки.
Связь по одобрению сама по себе не присваивает всем его версиям одно значение.

План импорта создаётся по текущим ревизиям энциклопедии. Новые технические варианты
ASTRA сохраняются без модельного года, если источник его не устанавливает.
Существующие годовые модификации дополняются только при точном техническом
соответствии и согласии всех возможных кандидатов по конкретному полю. Ручные
значения, действующие официальные источники и история подтверждений сохраняются.

Режим `apply` принимает точный SHA256 предварительного плана. Он сверяет исходные
ревизии, записывает новые неизменяемые ревизии и проверяет чтением каждый результат.
Манифест обновляется атомарными партиями по 32 модели; прерванное применение
продолжается с уже проверенных ревизий без создания дублей. Изменение администратором
той же модели между планированием и записью останавливает соответствующую операцию.

Обычный выпуск сайта отдельно проверяет `requiredAstraPlanDigests`: полное завершение
применения, точные ревизии, каждое обещанное годовое расчётное поле и его источник.
Технические варианты без года не выдаются за годовые расчёты. Прежние обязательные
исследовательские партии также проходят существующую проверку принадлежности индексу.
Факт активации подтверждается только успешным штатным выпуском и публичным чтением.

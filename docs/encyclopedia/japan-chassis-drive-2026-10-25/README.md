# Привод по имеющимся кодам кузова

Проверка 25.10.2026 охватывает 335 сохранённых сочетаний марки, модели и кода (327 различных исходных кодов). Это инвентаризация имеющейся энциклопедии и сохранённых ответов японского фида, а не утверждение о полном ассортименте поставщика.

Проверены 490 официальных таблиц MLIT; извлечены 5503 строки совпадений. Использованы также заводские документы Honda, Mitsubishi, Daihatsu и Suzuki. В справочнике 238 однозначных связей, 46 неоднозначных и 51 неподтверждённая. Все части содержат не более 64 групп. Исходные большие книги не включены в приложение.

[Сводная таблица](table.md) содержит все проверяемые сочетания. `manifest.json` фиксирует контрольные суммы частей. Каждое доказательство содержит ссылку и лист/строку либо страницу документа. Для заводских выдержек `hashScope=reviewed_statement` означает хеш проверенного утверждения, а не скачанного PDF; для автоматического извлечения хеш относится к байтам книги.

92 заполнения пустого `drive` применены в двух пакетах: запуск 40161517645 завершился успешно, пропусков нет, новые ревизии прочитаны обратно. Из 168 исходных пропусков остальные 65 относятся к неоднозначным кодам, ещё 11 — к неподтверждённым значениям (включая три записи с `フメイ`, то есть «неизвестно»). Известный привод и записи со статусом ручной проверки не переписываются. Результат применения записывается отдельно: подготовленный пакет сам по себе не означает сохранения или установки сайта.

У общего кода Suzuki HA36S или Mazda BP8P встречаются передний и полный привод. Для такого автомобиля необходим отдельный точный признак; номер кузова сам по себе недостаточен. Наличие только одной комплектации в фиде также не доказывает уникальность привода у кода. Источник `PRIV` и ручные значения автомобиля сохраняют приоритет.

Неподтверждённые строки включают европейские типы/варианты, грузовые семейства Isuzu и некорректные коды. Они не становятся допущенными объявлениями и не получают придуманный привод. Существующие правила исключения грузовиков сохраняются.

Воспроизведение: `audit-japan-chassis.mjs` → `collect-mlit-chassis-drive.py` с официальными ссылками из `source-pages.json` → `build-japan-chassis-review.py` → `prepare-japan-chassis-batches.mjs`. Запись выполняется отдельным `encyclopedia-japan-chassis-apply.yml` с поэлементной проверкой исходного digest, сохранением ревизий и чтением результата. Остановка/повтор не требует пересоздания всех данных.

Ограничение поставщика `visitor_restricted` — самостоятельная причина недоступности живого поиска. Этот справочник не снимает ограничение доступа и не разрешает его обход.

# Прецеденты для моделей сайта — 25.10.2026

Дополнение содержит 35 записей для 27 ключей моделей. Все числовые значения сохраняются только как оценки по опубликованным прецедентам, не как подтверждённые сертификатные поля. Источники, тип измерения и ограничения находятся в data/catalog/power-reference/reported-power30-precedents.json.

Первичные отчёты AUTO BILD/ADAC дают семь прецедентов; собственные справочники импортёров aa-dv.ru и wersum.ru дают ещё 28 записей. Оригинальные сертификаты импортёров не просмотрены. Модель без известной версии может получить только модельный ориентир или диапазон. Для Li L7/L8, Xiaomi YU7, Zeekr 001, Toyota Levin, BYD Tang и Voyah Free сохранены различающиеся значения. Перенос из отчётов применяется только если основной документированный корпус не дал совместимого кандидата; существующую неоднозначность он не разрешает.

Runner обрабатывает сохранённую публичную проекцию и варианты энциклопедии только для присутствующих в ней моделей. Новые модели не создаются. Отдельные immutable части profiles содержат модель, технические входы и ссылку на решение; bindings содержат связи с текущими объявлениями. Каждый объект проверяется обратным чтением и checksum. Исходные коммерческие записи не публикуются.

Повторное применение возможно через тот же matcher к новым техническим входам. Автоматическое потребление производного справочника публичным калькулятором пока не реализовано. Сохранение профилей само по себе не означает изменение цен или отображаемых характеристик сайта.

# Object Storage PUT 400 при публикации каталога

Дата инцидента: 2026-07-29.

Production-run `Catalog source-scale daily #113` успешно дошёл до публикации и подготовил 4 977 проверенных объявлений по всем семи рынкам, но новая generation не была опубликована из-за ответа Yandex Object Storage `PUT 400`.

Защита от повторения:

- динамические ключи facet-индексов ограничиваются безопасной длиной;
- длинное значение получает стабильный SHA-256 суффикс, поэтому запись и чтение используют одинаковый ключ;
- ошибка Object Storage содержит XML code/message, относительный путь и размер тела запроса;
- публикация остаётся атомарной: старый manifest сохраняется, пока новая generation не записана полностью;
- интерфейс карточек, рублёвые цены, расчёты, шесть рынков и лимит до 30 фотографий не изменяются.

# Правки интерфейса — 20 сентября 2026

Запрос владельца: равномерные отступы расходов; пагинация и «Показать ещё» шириной двух карточек на десктопе; компактная итоговая цена с валютным блоком без сброса; вопрос под ценой; пара л.с./кВт во всех доступных случаях; единый способ открытия Алисы; общий фильтр электричек и гибридов с уточнениями; понятные русские характеристики с разделителями и иконками.

## Реализация

- Итог ручного/автоматического пересчёта использует существующий PriceTrend и окно курса. Суммы и формулы не менялись. Направление цвета берётся из реального изменения курса; без истории оно не выдумывается.
- Расходы показаны одной сеткой с одинаковыми вертикальными отступами. Убран повторный блок договорных платежей, уже присутствующих в расходах. Вопрос цены продавца перенесён под сумму.
- Пара единиц мощности показывается при наличии кВт, включая мощность вне порога утильсбора. Цвет порога остаётся прежним; точность входных данных и правил расчёта сохранена.
- ResearchLink объединяет открытие основного и гибридного поиска: узкое окно справа на десктопе, обычный безопасный переход на мобильном/при блокировке всплывающего окна. Надпись гибридной ссылки: «Алиса покажи тип гибрида и мощность». Проверенный текущий поиск Honda Civic показал быстрый ответ Алисы первым результатом. Расположением блоков на стороне Яндекса сайт не управляет.
- Новый query fuel=electrified выбирает объединение electric и hybrid; два отдельных чекбокса сохраняют существующие запросы fuel=electric и fuel=hybrid. Фильтр применяется на сервере до подсчёта и пагинации.
- Словарь русских названий дополнен английскими, немецкими, японскими и китайскими техническими терминами. Группы оформлены тематическими иконками и линиями; длинные значения переносятся. Неполные названия и остатки непереведённого текста доступны в разделе уточнений, исходные значения не угадываются и не удаляются из хранилища.
- Геометрия раскрывающихся полей в браузерном тесте измеряется одним снимком DOM: последовательные измерения при блокировке мобильной прокрутки давали ложный сдвиг 2 px. Проверки расстояний не ослаблены.

# Память публикации, Object Storage и скорость — 24.09.2026

## Диагноз

- Китай: запуск `35922669965`, публикация `107428747623` завершилась `JavaScript heap out of memory`.
- Европа: запуск `35940256627`, публикация `107456380432` завершилась той же ошибкой.
- У процесса публикации был лимит V8 6 GiB на стандартном публичном runner с 16 GB RAM. Перед сбоем heap составлял примерно 4,7 GB; одновременно удерживались свежий сбор, публичные записи и полный внутренний резерв.
- Object Storage в консоли Яндекса: 30,9 GiB из 50 GiB, около 7,2 тысячи объектов. Проверка API: 33 181 789 309 bytes. Дисковая квота не была причиной этих сбоев.
- Корея `35927387132`: другая причина — `catalog_public_regression_guard:korea:9368:12239`. Сохранён предыдущий каталог 13 598 автомобилей. Защита от массового сокращения остаётся включённой.

## Исправления

- Внутренний резерв читается последовательно по чанкам. Дубликаты, которые и раньше заменялись публичными записями, отбрасываются до накопления полного резерва. Неопубликованные записи сохраняют исходные технические доказательства.
- Ссылки на уже объединённый свежий сбор освобождаются до сортировки кандидатов.
- Для публикации на существующем runner выделено 12 GiB heap; число параллельных проверок кандидатов снижено с 12 до 4. Добавлены сведения о доступной RAM, heap и диске в журнал задания.
- Автоочистка запускается каждые 6 часов и после обновления Green Corner, помимо остальных рынков. Общий lock, защита текущей/предыдущей версии и grace 6 часов сохранены.
- В консоли Яндекса включено независимое правило `AbortIncompleteMultipartUpload`: прерывать незавершённые загрузки старше 7 дней. Правило не удаляет готовые объекты. Массовый TTL на весь бакет не задан: там также лежат заявки, клиенты и документы CRM.
- При первичной проверке квота не требовала изменения. Во время повторной публикации объём вырос; ниже зафиксированы последующая остановка Европы по резерву и согласованное владельцем увеличение квоты.
- Убрана публичная подпись Akebono из структуры цены и окна курса. Источник данных, инвойс CIF, иены, курс АТБ и расчёт таможни не изменены.
- Неизменившаяся поисковая проекция остаётся в памяти 5 минут вместо повторной загрузки каждую минуту. Проверка малого manifest сохраняется раз в минуту; новая версия каталога инвалидирует старую проекцию. Цены продолжают рассчитываться по действующим настройкам.

# АвтоЦена в Telegram — первая версия

Адрес приложения для BotFather: **https://avtocena.com/mini**.

Используются существующие каталог, фильтры, карточка, расчёт и форма заявки. Регистрация для посетителя не добавляется. Полная шапка и навигационные колонки подвала в мини-режиме скрыты; выбор города, условия сервиса, согласия и реквизиты доступны.

## Подключение владельцем бота

1. Открыть официальный @BotFather, `/mybots`, выбрать @avtocena_bot.
2. В Bot Settings → Configure Mini App включить Main Mini App и указать https://avtocena.com/mini.
3. Задать описание, иконку/экран загрузки и добавить превью приложения.
4. Открыть https://t.me/avtocena_bot?startapp и проверить каталог, несколько фильтров, переход в карточку, изменение расчёта и возврат.
5. Отправить `/start` боту в личном чате: новый ответ содержит кнопку «Открыть АвтоЦену», а меню чата настраивается для запуска приложения. Старые сообщения не редактируются.

Официальная инструкция: https://core.telegram.org/bots/webapps#launching-the-main-mini-app

## Границы первой версии

- Режим сохраняется в текущей вкладке; `?mini=0` выключает его. Для служебных разделов он не применяется и доступа к CRM не предоставляет.
- Telegram SDK используется для высоты окна, безопасных отступов, темы, кнопки назад и внешних ссылок. Telegram initData не используется для входа или доверенной идентификации пользователя.
- Каталог по /mini доступен и в обычном браузере для предварительной проверки. Эмуляция SDK не заменяет проверку внутри Telegram iOS/Android/Desktop.
- Автоматический вход, платежи, подписки и отдельная база автомобилей не добавлены.
- Появление Main Mini App в профиле и его настройки зависят от завершения настройки BotFather. Попадание в популярные приложения не гарантируется.

Рекламная ссылка после подключения: https://t.me/avtocena_bot?startapp. Telegram Ads допускает продвижение ботов; запуск объявления требует отдельной модерации. Правила: https://ads.telegram.org/guidelines

## Канал и группа TopAvto

Прямая ссылка на приложение: https://t.me/avtocena_bot?startapp=topavto. Её можно поместить в описание и закреплённое сообщение. Она запускает Main Mini App без предварительного /start; первый запуск может потребовать подтверждения Telegram.

Владелец или администратор, уже связавший личный Telegram с CRM, может отправить боту скрытую команду `/shareapp`. Бот ответит готовым сообщением с кнопкой «Открыть АвтоЦену». Его можно переслать в канал или группу и закрепить. Используется обычная inline URL-кнопка: web_app-кнопки личного чата не используются для групп и каналов. Автоматическая публикация в канале этой командой не выполняется.

Если Telegram не может соединиться с известным входящим сервером, обработчик сохраняет ожидающие события и переключается на опрос Telegram. Ответы на команды в этом резервном режиме зависят от расписания GitHub и могут задерживаться. Запуск по прямой ссылке приложения от обработчика команд не зависит.

# АвтоЦена

Сайт и каталог автомобилей, CRM, кабинет партнёра и расчёт стоимости.

## Рабочие документы

**Начинать с [правил рынков](docs/markets/README.md).** Затем открыть [общие условия](docs/markets/contract.md), [текущий шаг](docs/markets/current.md) и документ одного нужного рынка.

Новые источники, годы и интервалы утверждены владельцем 24.11.2026. Реализация начинается с Китая. Прежние описания открытых источников, общего импорта каждые шесть часов и паузы после удаления AJ заменены этими документами.

## Разработка

```bash
npm install
npm run dev
```

Локальный сайт: `http://localhost:3000`.

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Сайт и CRM |
| `npm run dev:bot` | Бот |
| `npm run build` | Сборка сайта |
| `npm run typecheck` | Проверка типов |
| `npm test` | Проверки проекта |

| Каталог | Назначение |
| --- | --- |
| `apps/web` | Сайт, API и CRM |
| `apps/bot` | Бот |
| `packages/engine` | Существующий расчётный движок |
| `docs/markets` | Короткие правила и текущий шаг |

Доступы и коммерческие данные сохраняются в существующей конфигурации и закрытом хранилище. Не помещать их в GitHub или логи.
